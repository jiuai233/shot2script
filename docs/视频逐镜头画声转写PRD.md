# 视频逐镜头画声转写 PRD

版本：1.2

## 1. 产品目标

将短剧视频转换为人物明确、动作具体、对白准确、上下文一致的制作剧本。内容按原视频镜头和播放顺序展开，交代每个片段中出现的人物、发生的动作、可见神态以及实际说话人。

人物说话时发生的动作需要与对白对应，能够形成“林舟拍桌子说道”这类具体表达。画面中其他人物的反应、独立动作和场景变化使用 △ 描写。全文经过独立验收 agent 审查后交付。

### 1.1 核心质量要求

1. 台词逐字准确，顺序与视频一致，不补写、改写或漏写。
2. 动作写清人物具体做了什么，保留动作过程、交互对象及重要结果。
3. 画面人物、动作执行者和说话人归属正确，画外对白和反应镜头能够区分。
4. 人物使用统一姓名或具体描述名；△ 及其他非对白描述不使用人物代词或含糊泛称。
5. 全文人物、称呼、动作和对白前后一致，验收发现的问题完成修正与复核。

## 2. 剧本内容与阅读形式

### 2.1 基本结构

正式剧本包含集标题、场景、时间与内外景、出场人物、△ 描述、人物对白及必要的画外或心声标记。

场景内按原视频镜头顺序展开。镜头切换、人物动作和对白衔接均应有对应记录；同一地点内的镜头切换不自动生成新场景。

镜头时间记录与剧本内容能够相互对应。正式稿保持剧本阅读形式，不将任务状态、分析过程和验收批注混入正文。

### 2.2 动作与台词的关系

- 说话人说话前、说话中或紧接说话发生的可见动作，需要放在对应对白附近，明确动作与台词的关系。
- 与说话同步的简短动作可以放在人物名后的括号中，例如“林舟（右掌拍在桌面上，抬高声音）：今天必须说清楚。”
- 较长动作、多人互动、独立动作、反应及场景变化使用 △ 展开，放在实际发生的位置。
- 同一动作不在括号和相邻 △ 中重复描写；必要的连续动作保留清楚的先后关系。
- 无可见动作时允许直接写对白，不为每句台词补造动作、表情或姿势。

### 2.3 表达示例

示例中的动作与声音均须在实际转写时取得素材依据。

> 第1集  
> 场景1-1：会议室，日，内  
> 人物：林舟、沈宁、穿红衣服的小男孩  
> △ 林舟走到会议桌旁，拉开椅子，把文件放到桌上。  
> 林舟（右掌拍在桌面上，抬高声音）：今天必须说清楚。  
> △ 沈宁停下翻文件的动作，抬头看向林舟。  
> 林舟（画外）：合同的最后一页还没有签字。  
> △ 穿红衣服的小男孩从门口走到沈宁身旁，把信封递给沈宁。  
> 沈宁（接过信封，低头查看）：原件在这里。

该示例中，林舟的拍桌动作与林舟的对白直接关联。画面转向沈宁后，持续说话的人仍可为林舟；沈宁的反应单独描写，不归到林舟的台词动作中。

### 2.4 场景划分

- 出现以下情况时新建场景：地点变化；同一地点时间不连续，例如日转夜或明显跳时；进入或结束闪回。
- 同一地点、时间连续的镜头切换，包括正反打、特写和插入镜头，不新建场景。
- 场景行格式为「场景{集号}-{序号}：地点，时间，内/外」，序号在本集内从 1 连续编号。
- 人物行列出本场出现或出声的全部人物，使用统一姓名或具体描述名。
- 地点无法确认具体名称时，使用画面可见的描述，例如“走廊”“病房”，不推测名称。

### 2.5 声音形态与特殊标记

| 情况 | 写法 | 判断依据 |
|---|---|---|
| 说话人在画面中 | 林舟：…… 或 林舟（动作、声音表现）：…… | 画面可见说话人 |
| 说话人不在画面中，或画面拍摄听者 | 林舟（画外）：…… | 说话人不可见，声音身份已确认 |
| 人物内心话 | 林舟（心声）：…… | 无口型，内容为心理活动 |
| 电话、视频、广播等设备传出的人声 | 林舟（电话）：…… | 声音经设备传出 |
| 闪回 | 场景行末标「（闪回）」，回到现实后另起场景行 | 视频的回忆、插叙画面 |
| 人物字卡、地点字幕、时间字幕 | △ 画面字幕：……（照录原文） | 后期叠加在画面上的说明文字，如“李桂芝 朵朵奶奶”“一小时前” |

- 手机屏幕、招牌、牌匾、纸张等画面中的其他文字不写入剧本。人物拿手机给人看、读信等动作照常按 △ 描写动作本身。
- 有口型的自言自语按普通对白写；无口型的心理内容写心声。口型无法判断时登记待确认，不在正式稿中猜定。
- 标记与动作、声音表现写在同一括号内，标记在前，例如「林舟（画外，声音发颤）：……」。
- 画外、心声和设备传出的台词，括号内只写声音表现，不写说话人在画面中不可见的动作。

## 3. 业务流程

### 3.1 素材准备与声音识别

- 按集接收视频，确认集号、时长、声音与画面可读取。
- 使用语音识别服务识别本集人声，获得对白原文、时间位置及可区分的声线信息。识别服务通过配置切换，不写死在流程中。
- 识别画面硬字幕，作为台词用字和断句的校对参考。台词以实际声音为准；识别结果与字幕不一致时回听对应时间段核对，仍不能确定的登记待核对。
- 保存声音与画面的时间对应关系；跨片段、跨镜头的对白保持连续。
- 同时说话、听不清、声音身份不明等情况明确登记，后续复核时保留原始材料。

### 3.2 角色建立与画面识别

- 结合声音、画面、姓名字幕、称呼及前后关系建立和补充本集角色卡。
- 按视频镜头顺序识别人物动作、表情、姿势及人物与物件的互动。
- 动作先明确属于哪个画面人物；姓名尚未确认时保留可区分的人物描述。
- 根据角色卡核对画面人物与声音人物的关联，不因镜头切换直接更换说话人。

### 3.3 成稿与验收

1. 按场景及镜头顺序组织对白、人物动作和 △ 描述。
2. 统一姓名与具体描述名，核对动作与对白的发生位置。
3. 独立验收 agent 根据全文、角色卡和对应素材审查内容。
4. 主 agent 将发现的问题交回相应职责处理，保留明确问题和修正结果。
5. 复核通过后交付单集剧本；返修后仍有未解决问题的集按 9.5 处理。
6. 多集完成后由全剧主控检查合并稿的跨集一致性。

## 4. 职责、任务范围与共享资料

### 4.1 职责分工

| 职责 | 内容要求 |
|---|---|
| 全剧主控 | 调度各集任务，审核跨集角色卡变更，组织多集合并与跨集一致性检查，汇总需人工裁定的未决问题 |
| 主 agent | 管理本集任务、提供必要资料、控制黑板访问、审核角色变更、处理冲突、组织返修并确认交付状态 |
| 角色卡 agent | 核对声音与画面身份，维护角色卡提案和人物对应关系，本集结束时提供有依据的简短性格总结 |
| 动作识别 agent | 识别具体动作、神态、动作双方和可见结果，保留时间位置及无法判断的内容 |
| 成稿 agent | 将已确认的画面、声音及角色资料组织为符合表达规范的剧本，不改变素材事实 |
| 验收 agent | 独立审查全文，核对人物一致性、具体动作、画声归属和正文规范，输出问题及复核结论 |

素材读取、切分、取帧、文件保存和格式处理由固定处理流程承担。内容识别任务不承担文件管理和进度记录等机械操作。

### 4.2 按集任务与跨集延续

- 主 agent 与生产子 agent 的任务范围以一集为单位，本集结束后不持续积累整部剧的对话内容。
- 全剧角色卡持续保留，各集继承已确认人物和称呼资料。
- 动作识别只使用当前片段及必要的前后信息，不要求反复读取整集全部材料。
- 跨镜头延续的动作和说话状态能够承接；跨集人物身份保持一致。

### 4.3 受控黑板

黑板包含角色资料、本集声音与画面记录、待核对问题、成稿和验收状态。

- 黑板读写由主 agent 控制，子 agent 只能获取授权范围内的资料。
- 子 agent 提交识别结果或修改建议，不得擅自覆盖公共角色卡、改动其他任务结果。
- 人物合并、姓名修改和归属冲突经主 agent 审核后统一更新。
- 资料不足或结论冲突时保留待确认状态，不直接写成确定事实。
- 已确认人物或称呼发生变化时，相关全文内容一并核对，不留下新旧称呼混用。
- 本集主 agent 可以新增本集人物、补充已确认人物的本集资料。合并或拆分人物、修改已确认姓名等跨集变更提交全剧主控审核；影响已交付集时，列出受影响的集和位置，更新后对这些集重新核对称呼与归属。

## 5. 角色卡与统一命名

### 5.1 角色卡内容

每个角色保留以下资料：

1. 统一姓名或具体描述名，以及已确认的别名和称呼。
2. 可区分的外观特征、参考画面与出场位置。
3. 本集声线特征、相关对白及声音与人物对应的依据。
4. 角色关系、身份确认依据和待核对事项。
5. 有事件依据的简短性格总结，与身份事实分开记录。

声音编号仅代表相应听写范围内的说话人标签，不直接用于跨集认定同一人物。相似声线不自动视为同一人；同一人物出现不同声线标签时需要核对。

性格总结不用于猜测说话人、补写动作或改变对白。

### 5.2 姓名与描述名

- 已确认姓名的人物，非对白描述、人物列表和说话人标签均采用统一姓名。
- 未确认姓名的人物采用可核验、可区分的描述名，例如“穿红衣服的小男孩”“戴圆框眼镜的白发医生”。
- 同场出现相似人物时，描述名必须能区分各自身份，不交替使用同一含糊称呼。
- 同一人物跨镜头、换装及跨集保持身份连续，不随意改名或拆成不同人物。
- 姓名确认或描述名调整后，统一核对全文称呼。描述名与实际画面不能矛盾，旧称呼与新称呼的对应关系须明确。

对白中的原始人名、称呼和代词保持原文，不按正文命名规则改写台词。

## 6. 具体动作与 △ 描写规范

### 6.1 动作细度

描述应使动作可以被直接理解，包括实际发生的执行者、行为、交互对象及重要结果。动作连续发生时，保留必要步骤与先后关系。

例如，画面中实际存在拍桌说话时，应能写出“林舟右掌拍在桌面上”及对应对白，不能只留下“林舟（愤怒）：……”而遗漏拍桌动作。

画面中实际存在递物时，需要交代递出者、接收者和所递物件；存在推门、拉扯、打斗等动作时，需要交代动作对象及可见结果，不能只用“阻拦”“争执”“发生冲突”概括全过程。

关键动作指影响剧情事实、人物关系或对白理解的动作，包括：

1. 物品交接、取走、丢弃及所属变化。
2. 身体接触与冲突，如推、拉、打、抱、跪、拦。
3. 人物进场、离场及位置的明显变化。
4. 与对白直接关联的动作，如拍桌、指向某人或物件、出示证据。
5. 造成可见结果的动作，如摔碎、倒地、受伤、撕毁。

关键动作遗漏或无据属于阻断类问题（见 9.3）。

### 6.2 大白话与事实边界

- 使用自然、具体、容易理解的动作语言，避免小说式抒情、夸张比喻和抽象剧情总结。
- 可见神态应描述实际表情或表现，不将“意识到”“决定”“心怀鬼胎”等心理判断写成画面事实。
- 身体动作和表情必须与画面相容，声音表现必须与实际声音相容。
- 拍、敲、挥、推、点头等动态行为须能从视频过程或连续画面确认；静止姿势不能直接改写成完整动作。
- 不设置为了增加描写而强行补动作的要求，也不按动作行与台词行比例删除已经确认的动作。

### 6.3 △ 的人物指代硬约束

△ 使用大白话描写实际画面，人物必须采用角色卡中的统一姓名或具体描述名。该约束同时适用于台词括号中涉及其他人物的动作描述。

1. 禁止使用“他、她、他们、她们”等人物代词替代明确人物。
2. 禁止使用“男人、女人、小男孩、小女孩”等无法唯一指向人物的泛称；“穿红衣服的小男孩”等已登记、可区分的具体描述名允许使用。
3. 禁止用“对方、前者、后者、另一人”等含糊指代代替可明确写出的人物。
4. 涉及动作执行者、承受者、交互对象及物品所属人时，应能明确对应具体人物。
5. 同一句主语已明确且未变化时，允许自然省略重复主语；跨句或多人互动不能造成指代歧义。

对白原文、画面中需要照录的文字及固有名称不按人物指代规则机械替换。

### 6.4 台词括号中的动作

- 括号内动作默认属于该台词的说话人；涉及其他人物时必须写明姓名或具体描述名。
- 仅在素材支持时记录说话人的动作、表情和声音表现，不要求每句凑齐固定成分。
- 画面拍摄听者反应、说话人在画外时，听者动作使用独立 △，不能放进说话人的括号。
- 动作先于对白、发生于对白中或紧接对白结束时，应保持实际先后关系，不随意移动动作位置。
- 多人互动或较长动作链使用 △ 展开，避免压进一个括号后丢失动作双方及过程。

### 6.5 △ 不写镜头语言

△ 写人物做了什么、场景里发生了什么，不写摄影机怎么拍。

1. 不写景别和运镜，如“特写”“近景”“远景”“俯拍”“镜头推近”“镜头拉远”“镜头跟随”“镜头扫过”“慢镜头”。
2. 不写剪辑和转场，如“画面切到”“镜头一转”“画面一黑”“白光一闪”“画面定格”“淡入淡出”。闪回和时间跳转按 2.4、2.5 用场景行和画面字幕表达。
3. 不用“画面中”“画面里”“镜头前”“画外”作为 △ 的叙述框架；画外只用于对白的声音标记。
4. 特写或插入镜头里拍到的动作，直接写动作本身和执行者。例如手部特写中麻将牌从手里掉落，写“△ 李桂芝松开手，‘中’字麻将牌掉在地上。”
5. 正反打、特写等同一地点内的镜头切换不单独写 △；切换后出现新的动作或反应时，写这个动作或反应。

### 6.6 去掉 AI 腔

△ 和括号动作用说话一样的短句，主语加动作加对象，按发生顺序写。以下写法不出现在正文中：

1. 比喻、拟人、排比和对仗，如“像一尊雕像”“雨水仿佛在哭泣”。
2. 渲染气氛的句子，如“空气仿佛凝固”“气氛降到冰点”“一场风暴即将来临”。
3. 套路化修饰，如“眼中闪过一丝……”“嘴角勾起一抹……”“缓缓地”“不禁”“下意识地”“若有所思”“意味深长”“无声地”。
4. 评价和总结，如“这一幕让人心酸”“显然”“看得出来”“终于”。
5. 一句话堆叠三个以上动作或多层修饰。动作多时拆成几句，每句写清一个人做了什么。

神态写看得见的样子，如皱眉、瞪着林舟、哭、笑、低头。

示例：

> 不符合：△ 镜头缓缓推近，李桂芝眼中闪过一丝慌乱，手中的麻将牌无声滑落。  
> 符合：△ 李桂芝松开手，“中”字麻将牌掉在地上。

### 6.7 动作执行者不能错

△ 和括号动作中，每个动作的执行者和对象都必须有画面依据，不能按剧情、对白内容或“谁是主角”分配。

1. 正文中的每个动作都能对应到动作记录中的条目和依据帧。成稿时不得换执行者、补加执行者或把两人的动作合并到一人身上。
2. 只拍到手、背影、侧影等局部时，按衣着、饰品、位置的连续性确认是谁；确认不了的，写可区分的描述，如“戴玉镯的手”，并登记待核对，不猜成某个具体人物。
3. 同场有外观相近的人物时，描述名必须用能区分彼此的特征，动作记录和正文中不能混用。
4. 反应镜头中的动作属于画面里的人，不属于正在说话的人；说话人在画外时，其台词括号中不写画面里其他人的动作。
5. 片段交接处的前后衔接镜头只用于判断动作承接，不能把相邻片段的画面内容写成本片段的动作。
6. 同一人物在不同场景、天气或时间出现时，按 5.2 保持身份连续；外观因淋雨、换装等变化时核对后合并，不拆成两个人物。

## 7. 镜头、时间与声音归属

### 7.1 时间与镜头对应

- 每个视频镜头及对应动作、对白均能够定位到本集时间位置。
- 内容按原视频播放顺序呈现，闪回、插叙及时间跳跃保持视频实际顺序。
- 一个对白可以跨多个镜头，一个镜头可以有多人说话，不能强制一镜头只对应一个说话人。
- 切片或处理片段的边界不得被当作视频实际镜头或场景边界。

### 7.2 防止张冠李戴

- 分别识别画面中出现的人物、动作执行者和声音所属人物。
- 镜头从说话人转向听者时，持续对白保留实际说话人，并按画外对白表达。
- 镜头中有人出现、字幕落在某个人物身上，均不能单独证明台词属于该人物。
- 人物声线、口型、前后对白、姓名或关系信息相互冲突时，需要回到素材核对；不能只按剧情合理性选择人物。
- 归属无法确认时明确登记，不将未核实的人物归属作为确定内容进入正式交付稿。

### 7.3 其他声音

与剧情相关且实际可识别的环境音、音效及配乐变化可在对应位置简要记录。无对白画面保留实际动作或场景内容，不补写人声。

声音描述以实际音源为依据，不凭静态图片推断撞击声、脚步声或配乐变化。

## 8. 画面输入与识别效果要求

### 8.1 输入要求

- 输入画面需覆盖关键动作前后过程，能够区分静态姿势与实际动作。
- 镜头切换、快速动作、短暂表情、人物交接物品和说话人归属疑点应支持更细致的核对。
- 相邻片段交接处的动作和对白不能遗漏、重复或换错人物。
- 图片数量及采样密度需通过素材效果验证，重点检查关键动作漏写、无据动作、人物错配及说话人错归。
- 尚不能确认的动作保留问题，不以增加文字细节替代素材核验。

### 8.2 评测指标

采样方案和识别流程使用人工标注样本评测，以下指标按集统计：

| 指标 | 计算方式 |
|---|---|
| 台词逐字一致率 | 与人工校对台词逐字一致的句数 ÷ 人工校对总句数 |
| 说话人错归率 | 说话人标错的句数 ÷ 对白总句数 |
| 关键动作漏写率 | 未写出的关键动作数 ÷ 人工标注的关键动作总数 |
| 无据动作率 | 素材不支持的动作数 ÷ 正文动作总数 |
| 人物错配率 | 动作执行者或对象写错的动作数 ÷ 正文动作总数 |

各指标的上线门槛由总工根据首轮样本评测结果确定。采样方案或识别流程调整后，使用同一批样本重新评测。

## 9. 独立验收 agent

### 9.1 验收输入与覆盖范围

成稿后由独立验收 agent 结合全文、角色卡、镜头时间记录、声音记录和对应视频材料进行审查。

验收覆盖本集全文的所有场景、△、人物对白及动作括号。长稿可以分段审查，但需覆盖全部正文，并检查相邻段衔接；不能以少量抽样代替全文规范与一致性审查。

全剧合并后还需核对跨集人物身份、统一称呼和上下文连续性。

### 9.2 审查内容

| 审查类别 | 需要确认的内容 |
|---|---|
| 具体动作 | 素材中的拍桌、递物、推门、拉扯等动作是否被具体写出，动作过程和关键结果是否缺失；每条 △ 和括号动作的执行者、对象是否与对应帧一致，局部画面中的手、背影归属是否有衣着或位置依据，有无相邻片段画面混入；有无镜头语言、AI 腔修饰、评价总结或心理判断 |
| 动作与对白关联 | 动作是否属于该说话人，发生位置是否正确，有无把听者反应挂到画外说话人身上 |
| 人物指代与角色卡 | △ 和动作描述是否使用统一姓名或具体描述名，有无代词、泛称、同人多名及不同人物混用称呼 |
| 声音与画面归属 | 反应镜头、画外延续、多人对话和声音变更是否正确，有无张冠李戴 |
| 全文完整性与一致性 | 对白原文和顺序、镜头顺序、动作双方、物件及上下文是否一致，有无遗漏、重复、脑补或矛盾 |

正文与角色卡一致仍需核对素材归属；角色卡本身存在错误时，验收需指出角色资料问题，不能仅要求正文跟随错误信息。

### 9.3 问题与返修

每条问题应包含集号、场景或镜头位置、原文、问题类型、问题级别、相关人物、素材依据或证据缺口、修正要求及复核结果。

问题分为两级：

- 阻断类：台词遗漏、改写或顺序错误，说话人错归，人物错配，关键动作遗漏或无据，动作执行者或对象错误，剧情事实矛盾。
- 规范类：△ 中的代词、泛称或歧义指代，△ 中的镜头语言或 AI 腔，括号与 △ 重复描写，非关键动作细度不足，称呼不统一，正文混入分析内容。

两级问题均须修正并复核后才能通过验收。

验收 agent 输出审查结论和问题，不随意改动公共角色资料。主 agent 控制返修范围和资料更新，完成修正后复核问题位置、相关上下文及全文名称一致性。

素材不足、身份未明、动作过程未确认等问题需明确列出；未解决时不能标记为正式验收通过。

### 9.4 验收通过标准

1. 全文均已完成审查，所有场景、△、对白及动作括号有明确审查范围。
2. 已确认的具体动作得到保留，并与正确人物及对白对应；无未解决的关键动作遗漏或无据动作。
3. △ 及其他非对白描述无未解决的代词、泛称或歧义指代，无镜头语言和 AI 腔，人物名称与角色卡及上下文一致。
4. 无未解决的人物错配、说话人错归、台词遗漏或改写、动作顺序错误及剧情事实矛盾。
5. 验收问题已修正并复核，最终正文与交付版本一致。

### 9.5 未决问题处理

- 每集返修最多 3 轮，每轮处理问题清单所列位置及受影响的上下文。
- 3 轮后仍有未解决问题，或问题因素材不足无法由 agent 判定时，本集状态记为“待人工裁定”，不标记验收通过。
- 待人工裁定的集输出当前稿和未决清单。未决清单逐条列出位置、各方依据、已核对的素材和需要裁定的问题。
- 人工裁定后由主 agent 更新正文和角色卡，验收 agent 复核相关位置及上下文后交付。
- 合并稿只收录验收通过的集。存在待人工裁定的集时，合并稿标明缺失集号，不作为全剧完整稿交付。

## 10. 交付内容

- 单集剧本及按集号顺序合并的全剧 Word 稿。
- 全剧角色卡、统一姓名及具体描述名对应资料。
- 可用于回查的镜头时间、动作和声音对应记录。
- 独立验收报告，包括问题、修正及最终结论。
- 待人工裁定集的当前稿和未决清单。

正式稿只保留剧本内容。角色分析、素材定位、任务过程、未决问题和验收说明分别保存，不混入人物对白或 △ 正文。

Word 稿按范本 `simple/范本_TG26090377假穷真爱_剧本合集_20260916.docx` 排版：

- 首页大标题为「{剧号剧名} 剧本合集」，各集按集号顺序排列。
- 集标题、场景行和正文使用三级样式，Word 导航窗格可按“集 → 场景”两级跳转。
- 对白、△ 和人物行使用统一正文样式，字体、字号与页面设置以范本为准。
- 交付前解析 Word 文件，实际检查集号连续、场景行格式、导航层级和字体，不以生成过程的汇报代替检查。

## 11. 重点验收场景

| 场景 | 预期结果 |
|---|---|
| 说话人拍桌、敲门或指向物件 | 具体动作与该人物对白直接对应，不只保留情绪标签 |
| 镜头拍 A、B 继续说话 | A 的动作单独描述，B 的台词正确标为画外，不将 A 的动作挂给 B |
| 多人递物、拉扯或打斗 | 动作执行者、对象、物件、过程和结果可辨，不用概括词代替全部动作 |
| 未具名人物及同场相似人物 | 使用明确、可区分的具体描述名，全篇稳定一致 |
| 同一人物换装或跨集出现 | 身份和正式称呼连续，描述名与画面不矛盾，不误拆新人物 |
| △ 出现代词或含糊泛称 | 验收明确指出具体位置并要求修正，原对白不被误改 |
| 无明显动作或无对白画面 | 如实记录可见内容，不强行补动作、台词或声音 |
| 角色卡与素材存在矛盾 | 验收指出身份依据问题，核对并修正相关角色资料和正文 |
| 全文存在漏动作、错归属或称呼混乱 | 列出问题并完成定向返修、上下文检查与复核后交付 |
| 无口型的心理独白与有口型的自言自语 | 前者标为心声，后者按普通对白；口型无法判断时登记待确认 |
| 插入闪回画面 | 闪回单独成场并在场景行标明，回到现实后另起场景 |
| 画面出现人物字卡、地点字幕或时间字幕 | 以 △ 画面字幕照录原文，不改写；手机屏幕、招牌等其他文字不写入剧本 |
| 特写、插入镜头或转场 | △ 只写镜头里人物的动作和结果，不出现“特写”“镜头推近”“画面切到”等镜头语言 |
| △ 出现比喻、渲染或套路修饰 | 改写为主语、动作、对象组成的大白话短句 |
| 只拍到手或背影的动作 | 执行者有衣着或位置依据；依据不足时用可区分的描述并登记待核对，不猜成具体人物 |
| 跨集发现两个角色实为同一人 | 提交全剧主控审核，更新角色卡后复核受影响的已交付集 |
| 返修 3 轮后仍有未解决问题 | 本集记为待人工裁定，输出未决清单，不标记验收通过 |
