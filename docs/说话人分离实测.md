# 说话人分离实测

声纹已支持按配置接入双路交叉核对，并提供跨集前三角色候选。T3g 的 E01–E03 副本由 25／25／23 类降到 7／7／7 类，人数上限参与了强制合并，尚无人工身份准确率。旧合成基准的独立台词留出比对为 5／5 正确；新合成第二集的首次 TTS 请求返回 HTTP 400，未完成。

第 1–8 节保留 T3d 的历史实验；T3g 的接口、数据和实测见第 9 节。所有候选仅供复核，不自动认定角色；正式黑板未在本轮实验中修改。

## 1. 环境与输入

- 实测日期：2026-10-17（UTC+8）；输入于 16:16:39（UTC+8）冻结。
- macOS 27.0.1、arm64、Python 3.12.13；CPU 两线程。
- `sherpa-onnx==1.13.8`、`sherpa-onnx-core==1.13.8`、`numpy==2.5.4`。没有安装 PyTorch、Demucs、SpeechBrain 或额外 ONNX Runtime Python 包。
- 合成输入：`tmp/T3/synthetic/benchmark.wav`，25.85 秒，十句真值、三种 TTS 音色。现有 Grok 记录九句，已漏掉重叠的 rex 台词；本工具不补写缺失台词。
- E01：`videos/sample/E01.mp4`，约 90.28 秒；冻结 29 句原始声音记录。未使用 T3c 后续切句修改，未改 ASR 后端或正式黑板。

冻结记录、原始响应及来源见 `tmp/T3d/inputs/`。合成时间真值来自 TTS 字符对齐，不是独立人工时间标注。合成音频没有专门添加配乐；去配乐的真实影响以 E01 为补充观察，但 E01 没有人工说话人真值。

## 3. 处理方式与命令

1. 按句时间定位 16 kHz 单声道音频；少于 0.5 秒的句子不建立聚类。
2. 超过三秒的句子等分窗口，单位化声纹向量后平均，再单位化。
3. 对可用向量做平均连接凝聚聚类。两类全部句对的平均余弦相似度达到阈值时合并，不预设人数。
4. 短句以自身向量匹配固定类中心，相似度严格超过阈值才归类；无向量或未超过阈值保持待定。
5. 至少一秒的句子比较前后半句声纹，低于 0.35 提示疑似重叠；实字词级 `speaker` 跳变或原记录重叠同样触发。零时长标点不算声线跳变。

待定和疑似重叠独立记录；疑似重叠句仍可参与聚类，因此混合声纹可能新建一类。相似度是余弦值，不是身份正确率。单句独立成类时，自身与类中心的相似度接近 1，不代表身份可靠。

```bash
uv run --with sherpa-onnx==1.13.8 python tools/diarize.py \
  videos/sample/E01.mp4 tmp/T3d/inputs/E01_声音记录.json \
  tmp/T3d/E01_新结果.json --模型 campp --阈值 0.60 \
  --词级 tmp/T3d/inputs/E01_raw.json
```

`--模型 resnet34` 切换对照，`--去配乐` 使用 Spleeter 双声道 44.1 kHz 分离后下采样。分离按十秒块、左右各一秒上下文裁回，保持原时间轴。`--重叠阈值`、`--分窗秒`、`--线程`、`--模型目录` 可配置。聚类阈值范围为 0–1；重叠阈值范围为 -1–1。

输出包含逐句标签、待定、疑似重叠及依据、类句数、类中心相似度矩阵、耗时与内存。已有输出拒绝覆盖。

`--写回 <声音记录.json>` 仅更新已定句的 `声线`，疑似重叠将 `听辨` 改为 `重叠`，其余字段保持不变。目标必须与分析输入一致，写回前保存带 UTC+8 时间的完整备份。当前黑板格式只允许 `E01-V1` 等标签，待定句保留原声线，并在结果的 `写回.保留原声线的待定句` 列出。旧标签不能当成本次确认结果；写回副本必须与结果侧表一起使用。

## 4. 四组合结果

所有组合使用聚类阈值 0.60、重叠阈值 0.35、三秒分窗、CPU 两线程。

句级纯度为各类真实说话人多数句数之和除以已分配句数；同时列出拆分类数，避免单句成类造成虚高。重叠句的文本只保留 eve，不能用该句文本标签证明混合音频只有 eve。主判断采用八句非重叠结果，全部九句指标见 `tmp/T3d/对比结果.json`。

| 组合 | 合成总类数 | 非重叠类数 | 非重叠纯度 | 非重叠拆分 ara/eve/rex | 重叠提示 | E01 类数/待定 |
|---|---:|---:|---:|---|---|---|
| campp+原声 | 4 | 3 | 100.0% | 1/1/1 | 1/1 | 18/4 |
| campp+Spleeter | 4 | 3 | 100.0% | 1/1/1 | 1/1 | 18/4 |
| resnet34+原声 | 3 | 2 | 75.0% | 1/1/1 | 0/1 | 13/3 |
| resnet34+Spleeter | 3 | 2 | 75.0% | 1/1/1 | 0/1 | 11/3 |

- CAM++：非重叠三个类每类纯度均为 100%；ara、eve、rex 各自没有被拆分。计入混合句后，eve 被分到两类，总计四类，全部九句按存留文本计算纯度为 100%。
- ResNet34：非重叠仅两类，eve 与 ara 被合并。混合类纯度 60%，rex 类 100%，加权 75%；加入重叠句的独立类后总数恰好为三，但并未正确区分三种音色。全部九句文本纯度为 77.8%。
- 两个 CAM++ 组合均标出已有的一个重叠句，八个非重叠句零误报；ResNet34 两个组合均漏报该重叠句。原声 CAM++ 该句前后半句相似度为 0.347522，接近 0.35 阈值，尚不足以确认检测稳定性。上游漏掉的另一句无法检查或恢复。
- E01 疑似重叠提示数量依次为 6、7、2、2；没有真值，不能称为真实重叠检出数。

## 7. 使用边界

实验默认组合为 CAM++ 原声，聚类阈值 0.60，重叠阈值 0.35，三秒分窗。去配乐增加内存和耗时，本轮没有合成纯度提升，也缺少 E01 真值支持，不默认启用。

| 情况 | 当前表现或风险 | 后续判断依据 |
|---|---|---|
| 混合人声 | 可能形成额外类；持续稳定的重叠不一定导致前后半句差异 | 原音回听、词级信息、口型与同时出声证据 |
| 极短应答、错误切句 | 声纹不稳定或待定，不能靠多建标签补足身份 | 扩大回听窗口、修正句时间，结合相邻镜头口型 |
| 配乐、音效、电话滤波、强情绪 | E01 类别变化已观察到，具体误分原因尚无真值区分 | 原声与人声轨对照、同人物多句角色卡证据 |
| 相似音色、不同文本 | 合成 eve 与 ara 在低阈值或 ResNet34 中合并 | 角色卡、独立回听、口型，不能只看余弦值 |
| 跨镜头或跨集 | 声纹类不等于姓名；反应镜头不证明说话人变更 | 角色卡 agent 综合口型、声线、称呼及时间连续性 |

前后半句差异只是疑点提示，不能区分多人重叠、正常轮流说话、音色变化和音频污染。本轮没有可用于 E01 自动身份确认的准确率结论，不能自动合并或拆分全剧角色卡。

## 9. T3g：约束聚类与跨集参考

### 9.1 输入与配置

实测日期：2026-10-17（UTC+8）。模型、原声处理和两线程配置沿用 CAM++、sherpa-onnx 1.13.8。黑板副本位于 `tmp/T3g/E01`、`E02`、`E03`，分别包含 37、38、46 句。全局配置未改，启用配置副本为 `tmp/T3g/models.json`。

配置顶层增加：

```json
"diarize": {
  "enabled": true,
  "model": "campp",
  "threshold": 0.6,
  "constraints": ["grok", "lipsync", "max_speakers"],
  "grok_weight": 0.15,
  "grok_purity": 0.7,
  "grok_min_similarity": 0.2,
  "max_speakers": 6,
  "threads": 2
}
```

`max_speakers` 是已知人数上限，最终目标最多为该值加 1 类；本轮按“五六人”采用实验上限 6。未给定时读取角色卡人数，角色卡也缺失时不启用人数限制。`constraints` 中删去名称可单独关闭相应约束；`enabled` 缺失或为 false 时交叉核对行为不变。

### 9.2 聚类机制与输出

1. Grok 词级标签按与当前句的重叠时长投票。主标签占比至少 0.7 时参与；平均声纹相似度至少 0.2 才允许加权。类间得分为平均余弦相似度加 `grok_weight × 同标签句对比例`。标签不同不形成硬分离。原始响应的标签不跨窗口延续；同窗口选最近成功响应，重叠的定向响应区域优先使用大窗口。
2. 口型条目须与当前句号、文本、起止时间匹配。`画内` 且唯一轨迹组 `开口` 的同组句形成 must-link；不同组、句时间重叠形成 cannot-link。单句多个组开口时登记冲突，不凭该句连接多个组。静音或无有效向量的句子保持待定。
3. must-link 先合并，随后按声纹及 Grok 得分聚类。人数上限不足时按最高可合并得分继续合并，依据记为 `max_speakers`。所有步骤及短句吸附均遵守 cannot-link；硬约束冲突保留分离并登记，即使最终超过人数上限。
4. 逐句输出声线、相似度、置信度、合并依据、待定和重叠疑点。置信度为最终类中心余弦值截断至 0–1，未经概率校准。单句类接近 1 不代表身份可靠。每类最多提供三句非重叠优先的代表句。
5. `asr_cross.py` 在合并后、写黑板前运行声纹；只更新非待定句的声线，不改变文本、时间、听辨及核对状态。结果侧表为本集 `声纹聚类.json`。待定句保留旧标签，跨集比对依据侧表排除，不把旧标签视为已归类。

独立聚类示例：

```bash
uv run --with sherpa-onnx==1.13.8 python tools/diarize.py \
  videos/sample/E01.mp4 tmp/T3g/E01/输入声音记录.json tmp/T3g/E01/新聚类.json \
  --约束 grok lipsync max_speakers --人数上限 6 \
  --口型 tmp/T3g/E01/口型记录.json --词级 <Grok响应.json> \
  --试听目录 tmp/T3g/E01/新试听
```

旧命令不带 `--约束` 时保留原始无约束聚类。独立工具 `--写回` 的重叠听辨行为保持不变；交叉核对步骤只写声线。
