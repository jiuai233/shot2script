## 2. 接口与凭据

### Grok 语音转文字

使用 `POST https://api.x.ai/v1/stt`，模型 `grok-voice-transcribe-2.0`，发送 `language=zh`、`diarize=true`、`format=false`、`filler_words=true`。`keyterm` 可重复传角色卡姓名，最多 100 项，每项最多 50 字符；文件字段位于最后。

非空 `XAI_API_KEY` 优先；空值或未配置时，通过 `pi auth print-bearer-token --provider xai` 获取 Pi 已登录凭据，由 Pi 刷新过期令牌。命令输出仅在内存捕获，最多等待 30 秒；失败时不转发标准输出、标准错误或子进程异常内容。STT 和合成脚本共用此入口。本次实际来源为 Pi xAI OAuth，没有复制登录文件或将令牌写入磁盘。

服务实际返回逐字/词 `start/end/speaker`。整集 421 个词条中，65 个标点为零时长，均不含实字。后处理保留这些标点；换人处标点归前一句，不生成标点独立句。零时长实字仍拒绝。当前按说话人变化、至少 0.35 秒的停顿和句末标点分句；超过 6 秒的原句进一步按逗号分段，无标点时仅在服务词条边界限制时长。句内短于 0.3 秒的声线跳变并入相邻连续片段，受影响句标“听不清”；独立短应答保留声线。儿化后缀不独立成句，不伪造词内时间。输出时间精度为 0.1 秒，原始精度保存在响应文件。

官方文件上限为 500 MB；一小时分段是本地策略，不是服务时长承诺。相邻分段重叠一秒；本次 90 秒整集没有触发长音频分段，真实长音频效果未测。

### Grok 文字转语音

使用 `POST https://api.x.ai/v1/tts`，通过 `voice_id` 指定音色，`language=zh`，`with_timestamps=true`，输出 16 kHz WAV。十次调用均成功，取得三个指定音色的中文音频、Base64 音频响应及字符时间。

八句非重叠合成对白被 STT 全部按已知输入文本识别，支持本次样本的中文可识别性；未进行人工音质、自然度或口音评分。三个不同音色 ID 并不保证 STT 能区分：`ara` 与 `eve` 在本次识别中合为一个标签。

### 豆包音频理解

参考 `../v2t/tools/ark_asr.py` 的 `build_payload/call_once`：`https://ark.cn-beijing.volces.com/api/v3/chat/completions`，模型 `doubao-seed-2-0-lite-260428`，裸 Base64 `input_audio`，`format=wav`，显式代理且不继承系统代理。

句时间、声线、听辨由提示词要求输出，属于生成结果，尚无成功响应证明其精度。实现每段最多 600 秒、文件小于 25 MB；Base64 和 JSON 另有传输开销。

## 7. 结论与待选补充方案

### Grok

已满足：Pi OAuth 和密钥入口、中文真实请求、原生词时间和标签返回、句列表生成、整集记录保存、绝对时间窗口识别、三音色合成。合成非重叠文本 8/8 一致，时间与 TTS 对齐参考接近。

未满足：三集人工台词准确率和独立人声时间误差验收；可靠的声线区分和重叠识别。三个合成音色被合为两个标签，重叠漏一句且未提示；E01 有字幕差异、疑似漏句和时间/声线切分异常。背景音乐强弱分层和真实长音频跨段效果也未验收。

适用范围：带原始响应依据的转写初稿及定向回查入口。声线标签不能直接当人物身份，“清楚”不能视作已经人工确认无漏句。

### 豆包

离线接入和结构解析已完成，真实请求仍未成功。服务可达性、文本、生成式时间、声线、重叠与配乐表现均未验收；阻塞仍为代理连接失败。

### 待总工选择

1. 指定 E01 逐字回听和人工时间打点的负责方式，重点核对本文 3.1、3.2 的异常；另提供其余两集样本，完成三集评测。
2. 声线或重叠要求不能由后续人工核对承担时，可另行评估本地独立说话人分离/重叠检测模型；需验证授权、资源和中文短剧效果。本轮未引入。
3. 若人工打点确认时间偏差影响镜头对齐，可评估本地强制对齐；漏句须先补齐文本，强制对齐本身不能恢复漏掉的语音内容。

## 8. E01 转写改进实测

测试日期：2026-10-17，UTC+8。当前文件为 41 句；全集最长句由 10.6 秒降至 4.5 秒，58.3–68.9 秒原句拆为 7 句，最长 1.7 秒。新增“桂芝，人呢？”及独立窗口复查的“小孩儿，让开！”均标“听不清”，人物身份未确认。

### 8.1 数字格式与配置

`asr.backends.grok.format` 接受布尔值，默认 `false`，请求固定带 `language=zh`。E01 的 `format=true` 实际请求中，顶层 `text` 和 `words` 都保留“八百、三点四十、四点十分”，未得到 `800、3:40、4:10`。同口径对照的用字差异组从 10 变为 11，整串字幕编辑距离从 42 变为 44；本样本没有数字改善证据。该次响应还出现“朵朵的、我女儿的”等差异，不能把两次响应全部差异归因于格式参数。

Grok 后端可配置字段及缺省值：

```json
{
  "format": false,
  "pause_seconds": 0.35,
  "max_sentence_seconds": 6.0,
  "min_speaker_seconds": 0.3
}
```

`vad_threshold` 为可选的 0–1 数值；整集不配置时保留服务默认门限。疑似漏句窗口使用 `vad_threshold=0`，不改变后续整集请求的设置。E01 当前候选整集使用 `vad_threshold=0`，这项样本设置未改为全局缺省值。

### 8.4 人名提示与补识别用法

```bash
uv run python tools/asr.py videos/sample/E01.mp4 tmp/下一轮/E01 \
  --provider grok --keyterm-from 剧目/样本剧/E01/字幕记录.json \
  --recover-from 剧目/样本剧/E01/字幕记录.json

uv run python tools/asr_window.py videos/sample/E01.mp4 00:49.3 00:51.8 \
  --provider grok --keyterm-from 剧目/样本剧/E01/字幕记录.json \
  --raw-dir tmp/下一轮/window/asr_raw
```

`--keyterm-from` 可重复传入角色卡或字幕记录，与 `--keyterm` 及配置中的提示词合并去重。角色卡读取姓名类型的名称和别名称呼；字幕读取反复出现且有呼唤、接人等语境的 2–3 字候选，排除代词和亲属泛称。候选只影响服务提示，不修改角色卡或按字幕替换转写。E01 提取到“朵朵、桂芝”；带提示词的整集响应中“慧芝”消失，“朵朵”由 2 处增至 3 处，“躲躲”消失。单次提示词响应也曾漏掉“糊啦”，识别结果存在波动。

整集工具默认在本集已有 `字幕记录.json` 时自动回查“只有字幕”的位置，也可用 `--recover-from` 指定来源、`--no-recover` 关闭。每侧扩 1 秒；低于 0.4 置信度和零时长字幕不触发自动补识别。已有长句中的同文台词不重复追加；窗口上下文及与原句明显重叠的结果不追加。新增结果只采用音频服务原文，标“听不清”，声线使用窗口独立命名空间。诊断保存在 `素材/asr_raw/recovery.json`，命令输出包含回查、新增和失败数量。本样本实际自动补识别新增 0 句，功能成功插入路径仅经模拟服务测试，不能写成实测补句成功。

### 9.1 输入与规则

`tools/s2s/vad.py` 使用本地 `models/asr/fsmn-vad/`，在 `envs/local-asr/` 中执行 FunASR ONNX 检测，输入为 16 kHz 单声道 PCM16。检测尾静音参数为 200 ms，关闭端点扩展，输出本集绝对秒数的人声段。模型和配套文件必须已存在。

`tools/s2s/asr/segment.py` 按人声段建立候选句，`min_pause` 默认 0.5 秒，`max_sentence` 默认 6 秒。两路实词跨度用于否决会切入词内的边界。句界选择停顿中的低短时能量位置，保存精度为 0.1 秒；长句在最长可用停顿处继续拆分。缺少可用停顿时保留超长句并进入回听，不推造词内时间。两路词按中点进入同一组句界；只有一路识别出的内容保留。

字幕只在人工回听页展示，标注“参考，可能不准”。自动优先级使用两路文字差异、单路缺失、句长与截断；人名来源仅接受角色卡。`asr.py` 只有在已有副路词级结果时，才回查人声中两路均无词的区间。该区间至少 0.5 秒，回查窗口前后各扩 1 秒。

回听本句片段前后各补 0.2 秒，上下文覆盖时间相邻的前一句开头到后一句结尾。页面记录句号、文本、起止摘要；应用结果仅用这四项判断声音记录是否过期，其他字段的变化在应用输出中逐条列出。人工裁定仅在新旧句一一对应、起止完全相同时自动沿用；其他时间重叠映射显示原裁定，待再次确认。
