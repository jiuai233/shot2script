# 本地语音识别对比

默认后端建议保留 Grok；本地首选 Qwen3-ASR 0.6B，用于补漏和交叉核对，不能替代独立验收。Paraformer 热词版适合需要显式姓名提示的场景。Whisper 尚未取得可运行的完整权重。

## 1. 环境与比较范围

测试日期：2026-10-17，时间均为 UTC+8。硬件为 Apple M5、24 GiB 统一内存，系统为 macOS 27.0.1。Python 3.12.13。

- 原片：`videos/sample/E01.mp4`，统一为 16 kHz、单声道 PCM WAV，时长 90.27925 秒。
- 合成音频：`tmp/T3/synthetic/benchmark.wav`，25.85 秒、十句、三种音色，其中第 8、9 句同时发声。时间参考为 `ground_truth.json` 中的 TTS 字符对齐，尚无独立人工打点。
- Grok 原片：黑板当前 41 句版本，文件修改时间 **2026-10-17T16:22:39.037155+08:00**；本次读取时间 **2026-10-17T16:29:48.584854+08:00**。快照为 `tmp/T3e/comparison/grok/声音记录.json`。
- Grok 合成结果及服务耗时复用 T3 已成功的响应，不新增付费调用。未运行 SenseVoice-Small。

字幕仅为用字校对参考，不作为声音真值。各后端的切句数量不同，下面的“用字不一致”是对照组数量，不能直接相除得到准确率。所有推断仅针对这两份样本。

## 7. 本地接口与结果位置

`LocalBackend.transcribe(audio_path, start=None, end=None)` 返回 `list[Sentence]`。`model` 选择候选，`hotwords` 为字符串列表，`python_executable` 指定独立环境。

```python
from s2s.asr.local import LocalBackend

backend = LocalBackend({
    "model": "qwen3-asr-0.6b",
    "python_executable": "tmp/T3e/venv-local/bin/python",
    "hotwords": ["桂芝", "朵朵"],
})
sentences = backend.transcribe("videos/sample/E01.mp4")
```

从项目根目录以 `uv run python` 执行。输出时间为整集绝对时间，`speaker` 保持空字符串，交由说话人分离处理。Qwen 单次窗口最长 300 秒，超过时明确拒绝。所有候选默认停顿阈值 0.35 秒、目标最长句 6 秒，与 T3c 使用同一 `words_to_sentences` 实现。

现有声音记录数据格式不允许空声线，评测导出通过现有 `records()` 写入统一占位 `E01-V1`，该标签不表示全片只有一个说话人。语音分离前不可将此占位作为身份依据。本轮未修改注册表、配置或黑板。

采用的运行材料分三组：

- 原生 Paraformer：`tmp/T3e/runs/paraformer-zh-vad/`。
- 热词版及 Qwen：`tmp/T3e/runs/paraformer-contextual-final/`、`tmp/T3e/runs/qwen3-asr-0.6b-final/`，每个目录含无提示与姓名提示两组原片、合成结果。
- 对比及测试：`tmp/T3e/comparison/analysis.json`、`tmp/T3e/validation.json`、`tests/test_t3e_local.py`、`tmp/T3e/backend-window.json`。32 项单元测试通过，11 份声音记录格式校验通过；真实后端窗口调用返回空 `speaker` 和整集绝对时间。

## 9. 结论
