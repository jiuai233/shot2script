# 单集文稿检查

只根据输入的带行号工作稿、台词原文与时间、人物名称检查文稿，不看视频，不改稿。台词逐字、顺序、行号和人名统一已由程序检查，不重复列出。只找读文本就能发现的问题，按级别登记：

阻断（会让读者误解剧情）：
- 对白明显归错人：自问自答、电话或画外另一端的话归给接听者、称呼与说话人或被称呼者矛盾、前后对答接不上。
- 写了台词与上下文均无依据的关键事件或人物关系。
- 缺少场景行或人物行，或本场说话人不在人物行中，读不出谁在场。

规范（不影响理解）：
- 非对白中的代词或泛称、心理描写、无据情绪、文学修饰、镜头语言。
- 说话人短动作与 △ 用法不当，动作重复或提前。

说话人括号中的声音表现和神态来自素材，不按无据情绪处理，只指出心理推测或原因解释。拿不准时不判阻断。位置写正文行号，原文照录该行。没有问题返回空数组。只返回符合附带 Schema 的 JSON。
