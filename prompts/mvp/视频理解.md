# 整集视频理解

完整查看输入视频并听原声，按播放顺序记录可见事实及声音归属候选。输入为原生视频，服务端采样每秒 2 帧；未看清的短暂动作保留证据缺口，不以剧情补全。

只返回一个 JSON 对象，包含：
- 人物：数组，每项包含 id（T001 等临时编号）、具体外观、出现时间、跨镜头对应候选及依据。可附称呼关系候选，记录称呼原文、发话者、被称呼者及回应或连续性依据；外观特征和人物称谓分开记录。姓名须有人物字卡或可靠身份依据，不能直接把对白称呼变成姓名，也不能仅凭年龄确认亲属关系。最终统一编号与显示名由融合阶段确定。
- 动作：数组，每项包含 id（A001 等）、人物（临时编号或 null）、对象（编号、物件或 null）、起、止（整集秒数）、表述、依据、待核对（布尔）。包括进离场、递物、抓拉、掉落物等关键互动。区分姿势与动作过程，区分物件实见与猜测。
- 对白归属候选：数组，每项包含听到的短句、起、止、人物、形态（画内、画外、心声、电话、视频、广播或 null）、声音表现、神态、依据、待核对。声音表现写听到的音量、语速、哭腔、笑声、发颤等，神态写说话人可见的表情或视线，如皱眉、笑、瞪着某人；没有明显表现或看不到说话人时填 null。
- 待核对：数组，每项为含位置、依据、修正要求的对象，具体指出人物连续性、局部身体、遮挡、重叠、物件辨认等缺口。

时间仅为粗定位，不能冒充真实词时间。人物出镜、静态张嘴、字幕位置不能单独证明说话人；拍摄听者时持续人声不能自动换人。设备另一端的声音不能归给拿手机的人。字幕仅作参考，不替代原声。
动作写清执行者、对象、过程与可见结果，不写心理、原因、文学修饰、摄影语言。只有手、背影时检查衣着、饰品与位置连续性；无法确认用 null 并登记待核对。
不输出剧本，不调用工具，不追加解释或推理。
