# 整集视频理解

完整观看输入视频并听原声，按播放顺序记录看到和听到的事实。输入为原生视频，服务端每秒采样 2 帧；短暂动作看不清时如实登记缺口。

只返回一个 JSON 对象，包含：
- 人物：数组，每项包含 id（T001 等临时编号）、具体外观、出现时间、跨镜头对应候选及依据。可附称呼关系候选，记录称呼原文、发话者、被称呼者及回应或连续性依据。姓名来自人物字卡或可靠身份依据；外观特征与人物称谓分开记录。最终统一编号与显示名由融合阶段确定。
- 动作：数组，每项包含 id（A001 等）、人物（临时编号或 null）、对象（编号、物件或 null）、起、止（整集秒数）、表述、依据、待核对（布尔）。记录进离场、拨打或接听电话、递物、抓拉、掉落物等关键互动，区分持续姿势与动作过程，区分看清的物件与推测。
- 对白归属候选：数组，每项包含短句（听到的原话）、起、止、说话人、画面人物、形态、声音表现、神态、依据、待核对。
  - 说话人：发出这句声音的人的临时编号，依据音色延续、对答关系、称呼和看得清的嘴部动作判断；无法判断填 null。
  - 画面人物：这句话期间镜头里可见人物的临时编号数组。
  - 形态：画内、画外、心声、电话、视频、广播或 null。
  - 声音表现：音量、语速、哭腔、笑声、发颤等听到的特征；神态：说话人可见的表情或视线，如皱眉、笑、瞪着某人。没有明显表现或看不到说话人时填 null。
- 待核对：数组，每项包含位置、依据、修正要求，具体指出人物连续性、局部身体、遮挡、重叠、物件辨认等缺口。

判断说话人时以声音为主线：先听这句话的音色与前后哪句一致、是在回应谁，再看画面印证。镜头常拍听者的反应，这时说话人与画面人物不同，分别如实记录。从手机等设备传出的声音，说话人是设备另一端的人。

时间用于粗定位。字幕只作参考，台词以原声为准。动作写执行者、对象、过程和可见结果，用客观描述。只有手或背影时，依据衣着、饰品与位置连续性判断是谁，确认不了填 null 并登记待核对。只输出 JSON。
