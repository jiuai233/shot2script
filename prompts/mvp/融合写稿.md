# 单集音画融合写稿

根据输入的逐句语音与原生视频观察，先统一人物，再判断每句是谁说的，最后按播放顺序写成一集读者一读就懂的剧本。只返回符合附带 Schema 的 JSON。

## 人物与归属

- 每个人物使用一个 P001 等编号，关联其全部视觉人物；结合外观连续性、说话时间与画面证据、称呼与回应确认身份。
- 沿用输入中已确认的登记名。有可靠姓名用姓名；称呼者、被称呼者与回应都对得上时，可用唯一指向该人物的关系称谓；其余用具体外观名。外观、别称分别保存，正文始终使用同一个显示名。
- 逐句判断说话人时，先读懂台词本身：这句话在问谁、答谁，称呼指向谁，内容符合谁的处境，与前后句是否为同一人连贯说下去。再用视频观察的“说话人”“画面人物”和依据印证：两者一致时直接采用；不一致时按台词逻辑写最可能的人物，逐句归属的待核对填 true 并登记未决问题。
- 镜头常拍听者，说话人与画面人物不同时，台词归给说话人，镜头中的人有明显反应时写成 △。电话、视频另一端及画外的声音归给发声的那个人，并核对是否为已出现人物。
- 句内混人、重叠或证据冲突时登记未决问题。

## 剧本写法

- 第一行写“第{集号}集”。场景写“场景{集号}-{序号}：地点，时间，内/外”，序号连续；地点变化、明显跳时或闪回时分场，同一地点连续切镜属于同一场。紧接一行“人物：”，列本场出现或出声的全部人物显示名，用顿号分隔。
- 人物、地点、时间字卡照录为“△ 画面字幕：原文”。
- 人物行、说话人标签、△ 和括号中的人物写成 `{{P001}}` 等引用，由固定程序替换为登记名；对白冒号后的原文及字卡保持原样。
- 台词以语音句列表为准，每句按原顺序逐字使用一次，起止时间照录。同一人不间断地连续说出的相邻几句，合成一行对白，原文按顺序直接相连；换人、插入动作或明显停顿处另起一行。视频观察中的文字与时间作参考，与语音冲突时登记未决问题。
- 每条对白行的行首依次写所含原句的编号标记，如 `〔E01-S007〕〔E01-S008〕{{P001}}（打电话，焦急追问）：原文`；采用动作写在哪一行，就在该行行首写动作编号标记，如 `〔A001〕△ ……`。每个编号只标一行，行号由固定程序计算。

## 说话人括号

括号写这句话怎么说，像剧本里给演员的提示：一到两个短语，12 字以内。

- 语气要具体，结合声音表现、神态和台词本身选词，如“追问”“叮嘱”“催促”“不耐烦”“敷衍”“冷峻”“含泪坚定”“哽咽应答”“压低声音”“拍桌，提高音量”。
- 说话人本人直接伴随这句话的简短动作也可写入，如“皱眉”“翻白眼”；较长的过程、他人的反应和独立动作写成 △。
- 通话时写明通话方向：拨打方写“打电话”，接听方写“接电话”，后接语气，如“（打电话，焦急追问）”“（接电话，敷衍）”。画外、视频、广播等写明形态，如“（画外，声音发颤）”；这类听得到看不到的台词，括号只写声音。
- 声音形态按依据在逐句归属中填写画内、画外、心声、电话、视频或广播，不确定时填 JSON null。

## △ 动作

△ 写画面里发生的事：写清谁、对谁或什么物件、怎么做、结果如何，按发生时间放在对应台词之间。每个动作只写一次，只写视频观察中有依据的动作，用具体人名和客观描述，写人物本身的动作和去向，如“桂芝伸手拿起手机接听”“秋慧转身走出店门”。

## 输出与未决

人物表记录唯一名称、名称类型、命名依据、外观、别称和视觉人物。逐句归属照录输入的句编号、原文和起止；采用动作引用视频观察中的动作编号。依据各用一句话。

工作稿返回完整 Markdown，正文只写确定采用的内容。说话人拿不准时写最可能的人物，逐句归属的待核对填 true，并在未决问题登记，位置写句编号、动作编号或人物编号。语音异常、疑似漏段、视觉缺口和未确认的关键动作都登记为未决问题，困难内容完整保留在正文中。
