# 单集音画融合写稿

根据输入的逐句语音与原生视频观察，先统一人物，再判断对白归属，最后按播放顺序写完整单集剧本。只返回符合附带 Schema 的 JSON，不调用工具，不追加分析。

## 人物与归属

- 同一人物使用一个 P001 等编号，关联全部视觉人物。结合外观连续性、说话时间与画面证据、称呼与回应判断身份。
- 沿用输入中已确认的登记名，并核对对应人物。可靠姓名、能够唯一指向人物的已确认关系称谓均可登记；关系须有称呼者、被称呼者及回应等依据，不能只凭年龄或单次称呼确认。未确认时使用具体外观名。外观、别称分别保存，正文保持同一个显示名。
- 电话另一端或画外声音不能归给当前画面中的听者。人物转为电话声音时检查是否为已出现人物。句内混人、重叠或证据冲突登记未决问题。

## 剧本规则

- 第一行为“第{集号}集”。语音句列表是台词主文本，每句独占一行，按原句顺序逐字覆盖一次；不合句、拆句、改字、改起止时间。视频观察中的文字与时间仅作参考，冲突另列问题。
- 场景格式为“场景{集号}-{序号}：地点，时间，内/外”，序号连续。地点、明显跳时或闪回变化时分场，同地点连续切镜不分场。紧接“人物：”列本场全部出现或出声人物，只写显示名并用顿号分隔，不加括号或其他标记。
- 人物行、说话人标签、△ 和动作括号中的人物统一写成 `{{P001}}` 等引用，固定程序替换成登记名。对白冒号后的原文及照录字卡不替换。
- 每条对白行的行首写所属原句编号标记，如 `〔E01-S001〕{{P001}}：原文`；采用动作写在哪一行，就在该行行首写动作编号标记，如 `〔A001〕△ ……`，同一行多个标记依次相连。每个编号只标一行。不填写行号，行号由固定程序按标记计算。
- 说话人本人简短、直接伴随该句且不改变时序的短动作放在姓名后括号中；听者反应、独立动作或较长过程写 △。括号内容不超过 12 字，超出时改写 △。动作写清执行者、实际对象、过程及结果，不重复，不把说完后的动作提前。
- 视频观察中有依据的声音表现与神态写入说话人括号，如“（拍桌，提高音量）”“（画外，声音发颤）”“（皱眉）”；画外及设备声音只写声音表现。
- 仅写有依据的事实；不把台词内容当画面动作，不从静态姿势反推动作过程。不写人物代词或含糊泛称、心理推测、无据情绪、文学修饰和镜头语言；无新事件不造动作。
- 声音形态按依据填写画内、画外、心声、电话、视频或广播；画外、心声及设备声音括号不写不可见动作。形态未知填 JSON null，不添加动作括号。
- 只照录人物、地点、时间字卡，写“△ 画面字幕：原文”；不抄手机屏幕、招牌等其他文字。

## 输出与未决

人物表记录唯一名称、名称类型、命名依据、外观、别称和视觉人物。逐句归属照录输入的句编号、原文和起止；采用动作引用视频观察中的动作编号。依据各用简短一句话。

工作稿返回完整 Markdown 模板，正文不写待核对标记。说话人拿不准时写最可能的人物，逐句归属的待核对填 true，并在未决问题登记；问题位置写句编号、动作编号或人物编号。语音异常、疑似漏段、视觉缺口及未确认关键动作登记为未决问题，不确定事实不写成确定动作，不删除困难内容。不输出正式发布状态。
