# 角色提示词

按 `docs/视频逐镜头画声转写PRD.md` 的职责分工编写。每份提示词自包含，派发时把 `{{...}}` 占位替换为实际值，并按“你会拿到的资料”附上对应文件。

| 文件 | 角色 | 派发者 | 范围 |
|---|---|---|---|
| `00-数据约定.md` | 编号、黑板目录、数据格式 | 各角色共用 | 全剧 |
| `01-全剧主控.md` | 全剧主控 | 总工 | 全剧 |
| `02-单集主控.md` | 主 agent | 全剧主控 | 一集 |
| `03-角色卡.md` | 角色卡 agent | 单集主控 | 一集 |
| `04-动作识别.md` | 动作识别 agent | 单集主控 | 一个片段 |
| `05-成稿.md` | 成稿 agent | 单集主控 | 一集 |
| `06-验收.md` | 验收 agent | 单集主控、全剧主控 | 一集、一段或跨集 |

## 生产约束

所有生成式角色只用 `opencode-go/deepseek-v4.1-flash`，无其他模型回退。语音仅用本地 Qwen3-ASR，VAD、CAM++ 与口型组件提供本地候选证据。字幕不自动改写对白；异常回听按实际音频、时间和身份冲突触发。完整规范见 `docs/生产版PRD补充.md`，实现与验收状态见 `TODO.md`。

人物稳定 ID、全文统一名称、大白话动作、说话人短动作优先入括号及按实际时序组织适用于所有角色；违反生产补充第 8 节的项目均为 `阻断`。

## 单集流程

```
固定处理流程：镜头表 / 声音记录 / 字幕记录 / 帧图片
        │
        ▼
动作识别（按片段并行） ──► 角色卡（建立：人物映射 + 对白归属）
        │                          │
        └──────► 单集主控处理待核对 ◄┘
                       │
                       ▼
                     成稿
                       │
                       ▼
               验收（全文审查）
                       │
           ┌───────────┴───────────┐
           ▼                       ▼
    返修 → 复核（≤3 轮）        通过 → 正式稿 + 角色卡总结
           │
           ▼
      待人工裁定
```

## 派发时的资料隔离

| 角色 | 拿到 | 拿不到 |
|---|---|---|
| 动作识别 | 本段帧、衔接镜头、人声时间段、已确认人物外观、人物字卡、地点字幕、时间字幕 | 对白文字 |
| 角色卡 | 声音记录、字幕、动作返回的人物与嘴部可见状态、口型记录的句级与轨迹证据投影、声纹聚类、存在时的声纹候选、帧 | 工作稿、完整动作记录、声纹库原始向量及各集均值 |
| 成稿 | 已确认的动作记录、归属表、声音记录、角色卡、待核对清单 | 帧图片 |
| 验收 | 工作稿、对照表、角色卡、帧、声音记录、字幕 | 动作记录、归属表、其他 agent 的推理过程 |
