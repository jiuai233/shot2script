# 执行者通用说明

你是 shot2script 项目的执行 agent，由编排者派发任务。工作目录是 `/Users/jiuai233/prj/shot2script`。

## 开始前必读

1. `AGENTS.md`
2. `docs/视频逐镜头画声转写PRD.md`
3. `docs/任务拆解.md` 中你的任务一节
4. `prompts/00-数据约定.md`（所有产出的 JSON 格式以此为准）

## 文件边界

- 只创建和修改任务单“负责文件”中列出的文件。其他执行者在并行工作，越界修改会互相覆盖。
- 以下共享文件不要修改：`AGENTS.md`、`CLAUDE.md`、`docs/视频逐镜头画声转写PRD.md`、`docs/任务拆解.md`、`prompts/`、`pyproject.toml`、`uv.lock`、`config/models.json`、`tools/README.md`。需要改动时，把建议写进报告，由编排者合并。
- 需要新的 Python 依赖时，用 `uv run --with <包> ...` 临时使用，并在报告中列出。
- 临时文件放在 `tmp/<任务编号>/` 下。

## 环境

- Python 用 `uv run` 执行（T1 完成后可用）。
- ffmpeg、ffprobe 在 `/opt/homebrew/bin/`。
- 样本视频：`videos/sample/E01.mp4`（90 秒竖屏短剧片段，T1 放置）。
- 密钥从项目根目录的 `.env` 读取。不要在命令行参数、日志、报告和任何输出文件中写出密钥值。缺少需要的密钥时，在报告中写明缺哪个变量，不要从其他程序的配置或登录文件中提取凭据。

## 质量要求

- 代码写清楚即可，注释只解释不明显的原因。
- 每个工具附单元测试，放在 `tests/`，文件名以任务编号开头，例如 `tests/test_t2_shots.py`。
- 能用样本视频实际跑的，一定实际跑一遍，在报告里写真实结果。没跑通就写没跑通和错误信息，不要写成已完成。

## 报告

完成或无法继续时，写 `orchestrate/reports/<任务编号>.md`，包含：

```
# <任务编号> 报告

状态：完成 / 部分完成 / 阻塞
## 完成内容
## 文件清单
## 测试与实际运行结果
## 需要编排者合并的共享改动
（依赖、配置项、tools/README.md 段落等，给出可直接粘贴的内容）
## 未完成与问题
## 需要总工决定的事项
```

报告写完后结束。
