# T3h 只靠音频重新切句，并刷新三集黑板

问题：现在每句的边界由识别词级时间按 0.35 秒停顿切出，一句话常被切成两半（E01 的「奶奶，你等｜等我」「赶紧｜的」，S001 只有 0.1 秒）；回听片段按这些边界剪，听起来是半截；两路各切各的，合并时出现假分歧。

总工的约束：**字幕不可靠、不一定有，任何自动决策都不能用字幕。**切句、回听优先级、补识别触发、人名提示都只用音频、两路识别和角色卡。字幕存在时只能在人工回听页上作为参考展示。

## 1. 静音检测

- 用本地静音检测模型找出整集人声段。T3e 已下载 FunASR 的 FSMN-VAD（在 `models/asr/` 下，用 `envs/local-asr/` 环境调用；查看 `orchestrate/reports/T3e.md`）；不可用时用 Silero VAD 等本地模型，说明理由。
- 输出人声段列表（起、止），保存为 `<本集目录>/素材/人声段.json`。

## 2. 切句规则

1. 连续人声段作为候选句；段间停顿不少于 `min_pause`（默认 0.5 秒，参数化）才断句。
2. 断句点落在停顿区间内音量最低处（短时能量最小值），不落在字中间。
3. 候选句超过 `max_sentence`（默认 6 秒）时，在段内最长停顿处拆；识别结果的句末标点可以帮助选择拆分点，但只在该处确有停顿时采用。
4. 两路识别的词按时间中点归入同一套句子；有词跨越边界时把边界移到该词外侧。
5. 一集第一句之前、最后一句之后没有静音时，该句 `听辨` 之外另加 `截断: true`（写进报告由编排者合并 Schema），不补字。
6. 只有一路有词、另一路为空的句子照常保留，按交叉核对规则标 `仅主路` 或 `仅副路`。

## 3. 去掉字幕在自动决策中的作用

| 环节 | 改为 |
|---|---|
| 交叉核对优先级 | 只按两路归一化差异大小、仅一路识别出、句长与截断来定；不再读取字幕 |
| 漏句补识别（`asr.py` 的回查） | 由“字幕有、声音无”改为“静音检测判定为人声、两路都没有词”的时间段触发 |
| 人名提示 | `--keyterm-from` 只接受角色卡；传入字幕记录时报错并提示 |
| 回听页 | 字幕仍可显示（标为“参考，可能不准”），不参与排序；“采用字幕”按钮保留 |

`核对.字幕` 字段保留为可选展示字段。

## 4. 回听片段

- 片段按新句子边界再各加 0.2 秒剪。
- “带上下文”改为前一句开头到后一句结尾的整段。
- 只在声音记录定稿后生成回听页；回听页记录生成时的声音记录摘要，应用时只比较句号、文本、起止时间（声线等后续字段变化不阻止应用，但要在输出中列出）。

## 5. 刷新三集黑板

T9e 已生成新的镜头表和片段表（`tmp/T9e/<集>/`，每集多了一个白闪切点）。本任务一并刷新正式黑板 `剧目/样本剧/E01`–`E03`：

1. 替换镜头表、片段表、帧目录为 T9e 的新版本（先完整备份旧版到 `<本集目录>/素材/备份/<时间>-T3h/`）。
2. 用两路已有识别结果（`tmp/asr-compare/<集>/qwen3-asr-0.6b/` 与 `grok/` 下的声音记录，以及各自的原始词级响应；查看 T3c、T3e、T3f 报告确认原始响应位置）按新规则重新切句、交叉核对，**不重新调用识别服务**。
3. 声纹聚类按配置自动执行（`diarize`）。
4. 口型记录按新声音记录重算（`tools/lipsync.py --variant fused --复核`，用 `uv run --with 'mediapipe==1.1.1' --with psutil`），输出覆盖前先备份。
5. **E01 已有人工裁定**（`剧目/样本剧/E01/素材/回听/回听结果-20261017-声线同步.json`，16 句）：按时间重叠映射到新句子。新句与旧句一一对应且时间覆盖一致的，沿用最终文本并标 `人工确认`；拆句、合句或边界变化的，进入回听页，页面上显示“原裁定：……”供确认。映射结果写 `素材/回听/裁定迁移.json`。
6. 三集重新生成 `回听.html`。
7. 所有正式文件用 `tools/validate.py` 校验通过后才算完成；任何一步失败就恢复备份并在报告中说明。
