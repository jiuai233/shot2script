# T3f 两路识别交叉核对与人工回听页

总工已确认：每集同时跑两路语音识别，自动合并成一份声音记录；只有一路识别出、或两路不一致的句子标为“待回听”，交给单集主控优先核对。另外做一个人工回听页面，供总工逐句听音、选定正确文本。

两路默认是 Grok（主路）和本地 Qwen3-ASR（副路）。哪一路做主路，取决于编排者正在进行的三集对比，所以主副路必须由配置决定，代码里不写死。

## 负责文件

- `tools/s2s/asr/crosscheck.py`、`tools/asr_cross.py`
- `tools/s2s/listen/` 下的全部文件、`tools/listen_sheet.py`、`tools/apply_listen.py`
- `tools/s2s/schemas/声音记录.schema.json`、`tools/s2s/schemas/待核对.schema.json`（只做本任务需要的扩展，已有测试必须继续通过）
- `tests/test_t3f_*.py`、`tests/fixtures/t3f/`
- `tmp/T3f/`

配置项和数据约定的改动写进报告，由编排者合并。

## 配置

在报告中给出建议合并的配置：

```json
"asr": {
  "provider": "grok",
  "cross_check": {"enabled": true, "primary": "grok", "secondary": "local"}
}
```

`provider` 用于单路识别；`cross_check.enabled` 为真时，`tools/asr_cross.py` 按 `primary`、`secondary` 跑两路。

## 1. 合并：`tools/asr_cross.py <视频> <本集目录> [--主路结果 a.json] [--副路结果 b.json]`

- 不传结果文件时分别调用两路后端识别；传入时直接复用，方便对已有结果做合并。
- 按时间重叠对齐两路的句子，允许一句对多句。比较前去标点空格、统一全半角和数字写法（复用 `tools/s2s/sub_align.py` 的归一化）。
- 合并后的每句：
  - 两路一致：采用主路文本和时间，`核对.状态 = 一致`。
  - 两路不一致：采用主路文本，`核对.状态 = 不一致`。
  - 只有主路有：`仅主路`。
  - 只有副路有：插入该句，文本和时间取副路，`核对.状态 = 仅副路`。
- 有字幕记录时，同时记下时间重叠的台词字幕，作为第三方参考，不参与决定采用哪路。
- 声音记录条目新增可选字段：

  ```json
  "核对": {"状态": "不一致", "主路": "能出什么事，老是看着呢。", "副路": "能出什么事，老师看着呢。", "字幕": "能出什么事 老师看着呢", "优先级": 2}
  ```

  `状态` 为 `一致`、`不一致`、`仅主路`、`仅副路`、`人工确认` 之一。
  `优先级` 分 1 到 3 级，1 最高：仅副路和差异大的不一致为 1；与字幕一致的一路和另一路有小差异为 3；其余为 2。规则写进报告。
- 除 `一致` 外的每句，在 `待核对.json` 追加一条：`来源 = 识别`，`类型 = 全文完整性与一致性`，`级别 = 阻断`，`处理职责 = 回听`，问题写明两路和字幕的原文。已有同一句的条目时更新，不重复追加。
- 合并前备份已有 `声音记录.json`。输出合并统计：各状态的句数。

## 2. 人工回听页：`tools/listen_sheet.py <本集目录> <输出.html> [--全部]`

- 默认只列待回听的句子，按优先级、时间排序；`--全部` 列出所有句子。
- 为每句导出音频片段到 `<本集目录>/素材/回听/`：句子本身一段，前后各加 1.5 秒的上下文一段。用压缩格式（m4a 或 mp3），页面以相对路径引用。
- 每句显示：句号、时间、所在镜头的一张代表帧、主路文本、副路文本、字幕文本，三者的差异处高亮。
- 操作：
  - 播放本句、播放带上下文、重复播放。
  - 选“采用主路”“采用副路”“采用字幕”，或在输入框中手动修改文本。
  - `听辨` 选清楚、重叠、听不清。
  - 备注。
  - 标记“这里没有台词”（删除该句）。
- 键盘：空格播放，`C` 播放带上下文，`1`/`2`/`3` 选主路、副路、字幕，`J`/`K` 下一句、上一句，`E` 进入编辑。页面顶部显示进度（已处理 / 总数）。
- 进度存在浏览器本地存储里，关掉再打开能接着做；用 `try/catch` 包住存储读写，存储不可用时页面仍能用。
- “导出”下载 `回听结果.json`：每句的句号、决定（主路、副路、字幕、手改、删除）、最终文本、听辨、备注。
- 只用原生 HTML、CSS、JavaScript，离线可用，不引用外部资源。界面中文，按钮和提示用大白话。

## 3. 应用：`tools/apply_listen.py <本集目录> <回听结果.json>`

- 把最终文本、听辨写回声音记录，`核对.状态` 改为 `人工确认`，记录决定来源；删除标为“没有台词”的句子。
- 对应的 `待核对.json` 条目状态改为 `已裁定`。
- 写回前备份；句号变化时（删除、插入）重新编号，同时输出旧句号到新句号的对照表，保存在 `<本集目录>/素材/回听/句号对照.json`。
- 写回后运行 `s2s.validate` 校验声音记录和待核对。
