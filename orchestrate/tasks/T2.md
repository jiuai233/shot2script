# T2 镜头切分与取帧

任务说明见 `docs/任务拆解.md` 的 T2 一节。本任务单补充细节。

## 负责文件

- `tools/s2s/shots.py`、`tools/s2s/frames.py`、`tools/s2s/segments.py`、`tools/s2s/timefmt.py`
- `tools/shots.py`、`tools/dense_frames.py`、`tools/segments.py`（命令行入口，薄封装）

`tools/s2s/timefmt.py` 提供 `MM:SS.s` 与秒数互转，其他任务也会用到，接口保持简单：`to_sec(str) -> float`、`fmt(sec) -> str`。

## 输出格式

`prompts/00-数据约定.md` 只列了文件名，以下格式以本任务单为准，T5 的校验按同一格式实现：

`镜头表.json`：

```json
{
  "集": 1,
  "视频": "videos/sample/E01.mp4",
  "时长": "01:30.3",
  "镜头": [
    {"id": "E01-K001", "起": "00:00.0", "止": "00:02.4",
     "帧": [{"文件": "K001_01.jpg", "时间": "00:00.0"}, {"文件": "K001_02.jpg", "时间": "00:00.5"}]}
  ]
}
```

`片段表.json`：

```json
{
  "集": 1,
  "片段": [
    {"id": "E01-P01", "镜头": ["E01-K001", "E01-K002"], "起": "00:00.0", "止": "00:12.3", "衔接前": null, "衔接后": "E01-K009"}
  ]
}
```

- 帧图片存到 `<本集目录>/素材/frames/`，文件名 `K{三位序号}_{两位帧序号}.jpg`，长边 960 像素。
- 加密取帧输出到 `<本集目录>/素材/frames_dense/<起>-<止>/`，文件名带时间，例如 `t00-11.2.jpg`，并输出一个同目录的 `帧.json` 列出文件和时间。

## 要求

- 镜头检测用 PySceneDetect（ContentDetector 或 AdaptiveDetector），阈值做成参数。短剧常有快切和闪白，检测后合并短于 0.3 秒的镜头到相邻镜头，阈值做成参数。
- 取帧：每个镜头首（起点后 0.1 秒）、中、尾（终点前 0.1 秒）各一帧，加上按 `--fps`（默认 2）均匀补帧，每镜头最多 `--max-frames`（默认 12）帧，去掉与已有帧时间差小于 0.2 秒的帧。
- 镜头时间首尾相接覆盖整集，没有重叠和空隙。
- 片段划分：每段 6 到 10 个镜头，尽量均匀；最后一段不足 6 个时与前一段合并或重新均分。`衔接前`、`衔接后` 填相邻段的边界镜头。

## 实际运行

1. 在 `videos/sample/E01.mp4` 上运行，本集目录用 `剧目/样本剧/E01/`。
2. 生成核对图：每个镜头切换处取切换前最后一帧和切换后第一帧，拼成 `tmp/T2/镜头边界核对.jpg`（每行一个切换点，标注镜头号和时间），供总工人工核对漏切和误切。
3. 用 `tools/s2s/vision.py` 抽查 5 个切换点：把切换前后两帧发给识图模型，问“这两张是否属于同一个镜头”，结果写进报告。这只是辅助参考，不代替人工核对。
4. 报告写明：镜头数、平均镜头时长、最短和最长镜头、帧总数、运行耗时。
