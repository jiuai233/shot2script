# T3d 说话人分离

Grok 的说话人区分不可靠（合成基准中 3 个音色只分出 2 个，见 `orchestrate/reports/T3.md`）。本任务在本机加一层说话人分离：保留 Grok 的文字和时间，按句提取声纹并聚类，重新给出声线标签。总工已同意下载模型到本地试用。

## 负责文件

- `tools/s2s/diarize/` 下的全部文件
- `tools/diarize.py`
- `models/diarize/`（模型文件，`.gitignore` 由编排者处理）
- `docs/说话人分离实测.md`

- `tmp/T3d/`

T3c 正在并行修改语音识别和 `声音记录.json`。本任务不改 `tools/s2s/asr/` 和黑板中的声音记录，只读取；所有实验在 `tmp/T3d/` 下的副本上进行。

## 要求

### 1. 模型与环境

- 声纹模型：3D-Speaker 的 CAM++ 中文模型，优先用 sherpa-onnx 加载其 ONNX 版本（不依赖 PyTorch，兼容 Python 3.12）。从官方发布渠道下载到 `models/diarize/`，记录来源地址、文件名、大小和校验值。
- 对照：SpeechBrain ECAPA 或 sherpa-onnx 提供的其他声纹模型，任选一个。
- 人声分离（去配乐）为可选步骤：可以用 Demucs 等本地模型，需要 PyTorch 时单独评估安装体积，写进报告。
- 新依赖用 `uv run --with` 临时使用，在报告中列出，由编排者合并。不使用付费服务，不需要账号授权的模型优先。

### 2. 流程

`tools/diarize.py <视频> <声音记录.json> <输出.json> [--模型 campp|ecapa] [--去配乐] [--阈值 ...]`：

1. 按声音记录每句的起止时间切出音频（16 kHz 单声道），短于 0.5 秒的句子标为 `待定`，不参与聚类。
2. 每句提取声纹向量；句子较长时分窗取平均。
3. 聚类：凝聚聚类或谱聚类，按余弦相似度阈值决定类数，阈值参数化；不预设人数。
4. 待定句与最近类的相似度超过阈值时归入，否则保持待定。
5. 重叠检测：句内声纹在前后两半差异明显，或与 Grok 词级 `speaker` 跳变一致时，标记疑似重叠。
6. 输出 JSON：每句 `{"句": "E01-S001", "声线": "E01-V1", "相似度": 0.82, "待定": false, "疑似重叠": false}`，加上每类的句数和类间相似度矩阵。
7. 提供 `--写回 <声音记录.json>`：把结果写回 `声线` 字段，`听辨` 中疑似重叠的改为 `重叠`，写回前自动备份。本任务只在副本上使用该参数。

### 3. 评测

- **合成基准**：T3 生成的三音色测试音频及真值（在 `tmp/T3/` 下，查看 T3 报告确认路径）。指标：类数是否为 3、句级纯度（每类中占多数的真实说话人的比例）、同一真实说话人被拆成几类、重叠句是否被标出。
- **E01**：没有人工真值，报告类数、每类句数、每类代表句文本，生成 `tmp/T3d/E01_声线试听/`，每类导出 3 句音频片段，供总工试听判断。
- CAM++、对照模型、去配乐与否，至少 4 种组合的对比表。
- 记录每种组合的耗时和内存峰值。

### 4. 结论

报告中推荐默认组合和阈值，并说明：哪些情况仍会分错，需要交给口型检测和角色卡 agent 判断。
