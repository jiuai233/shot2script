# T11b 口型检测改进

T11 在 E01 29 句上的结论为：画内 6、未开口 5、看不到 7、存疑 11（见 `orchestrate/reports/T11.md`、`docs/口型检测实测.md`）。主要问题：侧脸漏检、嘴部与音量的相关性没有捕获可见嘴动、存疑过多。本任务按原计划加入主动说话人检测模型对照，并改进人脸检测。

## 负责文件

- `tools/s2s/lipsync/` 下的全部文件、`tools/lipsync.py`
- `models/lipsync/` 下新增的模型
- `docs/口型检测实测.md`
- `tests/test_t11*_*.py`
- `tmp/T11b/`

只读黑板文件。运行依赖用 `uv run --with`，在报告中列出。

## 要求

1. **侧脸检测**：E01 在 21.5 秒、55 秒有可见嘴部的侧脸，MediaPipe 未检出。加入一个对侧脸更稳的人脸检测器（例如 OpenCV 的 YuNet，或 sherpa-onnx、ONNX 生态中可在 CPU 运行的检测器），检测器漏检时作为补充，再取嘴部区域。
2. **主动说话人检测模型**：Light-ASD 或 TalkNet，查清官方代码和权重的发布渠道，能在 Apple Silicon CPU 或 MPS 上运行的优先。用人脸轨迹裁剪图和对应音频输入，得到每帧说话概率。需要 PyTorch 时在 `tmp/T11b/venv-asd/` 单独建环境，通过子进程调用，报告安装体积。
3. **融合**：每条轨迹的说话分数改为规则分数与模型分数的组合，权重参数化；两者冲突大时标 `存疑`。
4. **识图复核**：对融合后仍为 `存疑` 的句子全部运行 `--复核`（默认识图配置，不指定模型），统计复核与代码结论一致、不一致的数量。
5. **对比表**：T11 原版、加侧脸检测、加主动说话人模型、融合后，四个版本在 E01 上的四类结论数量、耗时、内存峰值。
6. 更新 `tmp/T11b/口型核对.html`，每句同时显示各版本的结论，供总工核对。

输出格式保持 T11 的 `口型记录` 结构，新增的字段（例如 `模型分数`）写进报告，由编排者合并到数据约定。
