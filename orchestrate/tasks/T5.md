# T5 黑板与机械校验

任务说明见 `docs/任务拆解.md` 的 T5 一节。本任务单补充细节。

## 负责文件

- `tools/s2s/schemas/`（每类数据一个 JSON Schema 文件）
- `tools/s2s/board.py`、`tools/s2s/validate.py`、`tools/s2s/coverage.py`、`tools/s2s/lint_script.py`
- `tools/board_init.py`、`tools/validate.py`、`tools/coverage.py`、`tools/lint_script.py`
- `tests/test_t5_*.py`、`tests/fixtures/t5/`
- `tmp/T5/`

## 数据格式

以 `prompts/00-数据约定.md` 为准。镜头表和片段表的格式如下（与 T2 一致）：

```json
{"集": 1, "视频": "videos/sample/E01.mp4", "时长": "01:30.3",
 "镜头": [{"id": "E01-K001", "起": "00:00.0", "止": "00:02.4", "帧": [{"文件": "K001_01.jpg", "时间": "00:00.0"}]}]}
```

```json
{"集": 1, "片段": [{"id": "E01-P01", "镜头": ["E01-K001"], "起": "00:00.0", "止": "00:12.3", "衔接前": null, "衔接后": "E01-K009"}]}
```

字幕记录在 4.3 的基础上允许附加 `框`、`置信度` 字段。

## 要求

### board_init

`tools/board_init.py <剧名> <集数>`：在 `剧目/<剧名>/` 下建立数据约定第 2 节的目录和空文件（JSON 文件写空结构，`状态.json` 写初始状态 `进行中`）。已存在的文件不覆盖。

### validate

`tools/validate.py <文件> [--type <类型>]`：按文件名推断类型，也可以显式指定。

- 用 JSON Schema 检查字段、类型、枚举值。
- Schema 之外的检查：编号格式与集号一致、编号不重复、时间格式 `MM:SS.s`、起不晚于止、引用的编号存在（例如动作条目的 `镜头` 在镜头表中存在，需要时读取同目录的其他文件）。
- 输出 JSON：`{"文件": ..., "通过": true/false, "错误": [{"位置": ..., "问题": ...}]}`；退出码 0 表示通过。

### coverage

`tools/coverage.py <本集目录> [--稿 工作稿.md]`：

- 声音记录中每个句号在对照表中出现且只出现一次；对照表中句号的出现顺序与时间顺序一致。
- 动作记录中每个 `关键: true` 的条目在对照表中有对应。
- 正文对白行的台词，与对照表所列句号的声音记录文本拼接后逐字一致（去掉标点和空格，统一全半角后比较）。
- 输出 JSON，列出每类问题及位置。

### lint_script

`tools/lint_script.py <工作稿或正式稿> [--角色卡 角色卡.json] [--正式稿]`：

逐行判断行类型：集标题、场景行、人物行、△ 行、对白行。对白行拆成说话人、括号、台词三部分，台词部分不检查用词。

检查项：

1. △ 行和对白括号中的人物代词：他、她、他们、她们、它们（指人时）。
2. 泛称：男人、女人、男子、女子、小男孩、小女孩、老人、老头、老太太、年轻人等，词表做成可配置的文件。角色卡中已登记的描述名（例如“穿红衣服的小男孩”）中包含的泛称不报。
3. 含糊指代：对方、前者、后者、另一人、另一个人、其中一人。
4. 画外、心声、设备形态（括号以“画外”“心声”“电话”“视频”“广播”开头）的括号中出现动作词，动作词表做成可配置的文件。
5. 场景行格式 `场景{集号}-{序号}：地点，时间，内/外`，可选末尾“（闪回）”；序号从 1 连续；每个场景行下一行是 `人物：`。
6. 对白说话人和人物行中的名称不在角色卡中（提供 `--角色卡` 时）。
7. `--正式稿` 时：残留 `【待核对`、`【说话人待核对`、时间码（`\d\d:\d\d`）、编号（`E\d\d-[SKAQP]`）。

输出 JSON：每个问题给出行号、行原文、检查项、命中词。

## 测试要求

- 每个检查项至少一个正例和一个反例。
- `docs/视频逐镜头画声转写PRD.md` 2.3 节的示例剧本（去掉引用符号 `>` 后）作为夹具，`lint_script` 零报错。
- 把示例中某条 △ 的“林舟”改成“他”，报出该行。
- 对白台词中的“他”“对方”不被报出。
- 用 `tests/fixtures/t5/` 下手工构造的一集完整黑板文件（镜头表、声音记录、动作记录、对照表、工作稿各几条），`validate` 和 `coverage` 全部通过；分别制造漏句、重复句、顺序错乱、关键动作未覆盖、台词改字，各报出对应问题。
