# T4 字幕识别

任务说明见 `docs/任务拆解.md` 的 T4 一节。本任务单补充细节。

## 负责文件

- `tools/ocr/vocr.swift`、`tools/bin/vocr`（编译产物，`.gitignore` 由编排者处理）
- `tools/s2s/subtitles.py`、`tools/s2s/sub_align.py`
- `tools/subtitles.py`、`tools/sub_vs_asr.py`
- `tests/test_t4_*.py`、`tests/fixtures/t4/`
- `tmp/T4/`

## 要求

### 文字识别

- 参考 `../v2t/tools/vocr.swift`，改写为输出 JSON：每个识别结果给出文字、置信度和归一化包围框（x、y、宽、高，原点在左上）。支持一次传入多张图片，减少进程启动开销。
- 用 `swiftc -O` 编译到 `tools/bin/vocr`。`tools/s2s/subtitles.py` 找不到可执行文件时自动编译。

### 字幕记录

`tools/subtitles.py <本集目录> [--frames <帧目录>] [--fps 2]`：

- 默认读取 `<本集目录>/素材/frames/`。T2 在并行开发，本任务测试时用 ffmpeg 自己按 2 帧/秒从 `videos/sample/E01.mp4` 取帧到 `tmp/T4/frames/`，用 `--frames` 指定。
- 相邻帧中位置相近、文字相同或高度相似（编辑距离比 ≥ 0.85）的结果合并为一条，起止时间取首次和最后一次出现。
- 类型判定（阈值做成参数，先在样本上观察后设定）：
  - `台词字幕`：画面下部固定区域、居中、单行或两行。
  - `人物字卡`：短文本，通常含姓名和身份，出现在人物附近或画面中部，持续时间短。
  - `地点字幕`：短文本，画面上部或角落。
  - `画面文字`：其他，例如手机屏幕、纸面、招牌。
- 过滤平台水印、角标等在整集中持续出现的固定文字，过滤规则写进报告。
- 输出 `字幕记录.json`，格式见 `prompts/00-数据约定.md` 4.3，并附加 `框` 和 `置信度` 两个字段。

### 字幕与声音对照

`tools/sub_vs_asr.py <本集目录>`：

- 读取 `字幕记录.json` 中的 `台词字幕` 和 `声音记录.json`。T3 在并行开发，本任务用 `tests/fixtures/t4/` 中你自己构造的声音记录测试；如果 `剧目/样本剧/E01/声音记录.json` 已经存在，也用它跑一遍。
- 按时间重叠和文本相似度对齐，允许一句对多条字幕、多条字幕对一句。
- 比较前去掉标点和空格，统一全半角。
- 输出 JSON 清单，三类：用字不一致（给出两边原文和差异位置）、只有字幕、只有声音。每条带时间和对应编号。
- 参考 `../v2t/tools/dict_alignment.py` 的对齐方法。

## 实际运行

1. 在样本视频上生成字幕记录，统计各类型条数。
2. 随机抽 20 条，把对应帧和识别结果一起用 `tools/s2s/vision.py` 让识图模型判断文字是否识别正确、类型是否正确，结果写进报告；同时生成 `tmp/T4/字幕抽查.md`（列出帧路径和识别结果），供总工人工核对。
3. 报告写明识别耗时、水印过滤情况、类型判定阈值。
