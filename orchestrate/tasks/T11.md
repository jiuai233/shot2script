# T11 口型检测

为每句对白判断画面中谁在开口，作为说话人归属和画内、画外、心声判断的依据。用代码量化嘴部开合与声音的同步，识图模型只做边界情况的复核。总工已同意下载模型到本地试用。

## 负责文件

- `tools/s2s/lipsync/` 下的全部文件
- `tools/lipsync.py`
- `models/lipsync/`（模型文件）
- `docs/口型检测实测.md`
- `tests/test_t11_*.py`
- `tmp/T11/`

只读取黑板中的 `镜头表.json`、`声音记录.json`，不修改。T3c 可能在运行中更新声音记录，开始时先复制一份到 `tmp/T11/` 并在报告中注明使用的版本。

## 要求

### 1. 模型

- 人脸与嘴部关键点：MediaPipe Face Landmarker（本机 CPU 运行）。模型下载到 `models/lipsync/`，记录来源地址、文件名、大小和校验值。
- 对照（可选，时间允许再做）：Light-ASD 或 TalkNet 一类的主动说话人检测模型，能在 CPU 上运行的优先。
- 新依赖用 `uv run --with` 临时使用，在报告中列出，由编排者合并。

### 2. 流程

`tools/lipsync.py <视频> <本集目录> <输出.json> [--fps 12] [--复核]`：

1. 对每句对白的时间段（前后各扩 0.2 秒）按 `--fps` 取帧，复用 `tools/s2s/frames.py` 的加密取帧能力，不跨越镜头边界时按镜头分段处理。
2. 每帧检测全部人脸及嘴唇关键点，按位置和大小把相邻帧的同一张脸连成轨迹。人脸过小（例如短边少于 40 像素）、侧脸角度过大或被遮挡时，该轨迹标为 `看不到`。
3. 每条轨迹计算嘴部张合比随时间的曲线。
4. 说话分数综合两项：句内嘴部张合的变化幅度（相对于该轨迹在无人声时段的基线）；嘴部张合变化与音频音量包络的相关性。权重和阈值参数化。
5. 每句结论：

   | 情况 | 结论 |
   |---|---|
   | 有轨迹分数超过阈值 | `画内`，给出该轨迹 |
   | 有清晰人脸但都低于阈值 | `未开口`（画外或心声候选） |
   | 没有可用人脸 | `看不到` |
   | 分数处于阈值附近 | `存疑` |

6. `--复核`：对 `存疑` 的句子，取 4 到 6 帧通过 `s2s.vision.ask` 问识图模型“哪个人在说话、嘴是否在动”，结果附在条目中，不覆盖代码结论。使用默认识图配置，不指定其他模型。
7. 脸与声线配对：统计同一声线标签的句子中，各条轨迹（按镜头内位置和外观，跨镜头用人脸关键点特征的相似度粗略合并）被判为开口的次数，输出候选配对和支持句数。

  "句": [

      "轨迹": [

        {"id": "E01-K004-F2", "框": {"x": 0.6, "y": 0.25, "width": 0.18, "height": 0.14}, "说话分数": 0.12, "状态": "未开口", "依据帧": ["..."]}

格式写进报告，由编排者合并到数据约定，名称为 `口型记录.json`。

### 4. 评测

- E01 全部句子跑一遍，统计四类结论的数量、耗时、内存峰值。
- 生成 `tmp/T11/口型核对.html`（离线、原生 HTML）：每句显示文本、时间、结论、各轨迹分数和一张标出人脸框的代表帧，供总工人工核对。
- 人工真值在 `eval/样本/E01/标注.json` 校对完成后可用；本任务先写好评测函数（结论与标注形态、说话人对比的准确率），用构造夹具测试。
- 报告中给出你在 E01 上看到的典型失败情况（快切、侧脸、遮挡、嚼东西、远景）。
