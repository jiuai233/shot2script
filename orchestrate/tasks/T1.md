## 要求

### 环境

- `uv init` 方式建立项目，Python 3.12 或以上，包名 `s2s`，源码在 `tools/s2s/`，`uv run python -m s2s...` 可以导入。
- 预装依赖：`pytest`、`jsonschema`、`httpx`、`pillow`、`lxml`、`python-docx`、`scenedetect[opencv]`、`python-dotenv`、`rapidfuzz`。
- `.env`：从 `../v2t/.env` 复制 `ARK_DOUBAO_API_KEY`、`ARK_DOUBAO_PROXY` 两行（用脚本复制，不要把值打印出来），再追加空的 `XAI_API_KEY=`。`.env.example` 列出全部变量名，值留空。

### 配置

`config/models.json` 结构：

```json
{
  "asr": {
    "provider": "grok",
    "backends": {
      "grok": {"api_base": "https://api.x.ai/v1", "model": "", "key_env": "XAI_API_KEY"},
      "doubao": {"api_base": "https://ark.cn-beijing.volces.com/api/v3", "model": "doubao-seed-2-0-lite-260428", "key_env": "ARK_DOUBAO_API_KEY", "proxy_env": "ARK_DOUBAO_PROXY"}
    }
  },
  "vision": {"runner": "pi", "model": "opencode-go/deepseek-v4.1-flash", "thinking": "off", "max_images_per_call": 12},
  "agents": {
    "default": {"runner": "pi", "model": "openai-codex/gpt-6.1-sol", "thinking": "high"},
    "动作识别": {"use": "vision"},
    "角色卡": {"use": "default"},
    "验收": {"use": "vision"}
  },
  "runners": {
    "pi": {"bin": "pi"},
    "opencode": {"bin": "opencode"}
  }
}
```

`tools/s2s/config.py`：

- 读取 `config/models.json`，环境变量覆盖：`S2S_ASR_PROVIDER`、`S2S_VISION_MODEL`、`S2S_VISION_RUNNER`、`S2S_AGENT_MODEL`、`S2S_AGENT_RUNNER`、`S2S_CONFIG`（换整个配置文件路径）。
- `agents.<角色>.use` 指向 `vision` 或 `default` 时继承对应配置，同时允许在角色下单独覆盖字段。
- 提供 `get_asr_backend()`、`get_vision()`、`get_agent(角色)`，返回解析后的配置对象。

### 运行器

`tools/s2s/runners.py`：同一个接口 `run(prompt, images=[], files=[], model, thinking, tools=False) -> 文本`。

- **pi**：`pi -p --no-session --no-context-files --model <model> --thinking <thinking>`，图片和附件以 `@路径` 传入；`tools=False` 时加 `--no-tools`。已验证可用：`pi -p --model opencode-go/deepseek-v4.1-flash --no-session --no-tools @帧.jpg "描述图片"`。
- **opencode**：先查 `opencode run --help` 确认非交互调用和附件参数，再实现同一接口；查不到图片附件方式时，在报告中写明，接口保留并抛出明确的错误。
- 超时、非零退出码、空输出都抛出带上下文的异常（运行器、模型、退出码、stderr 末尾 20 行）。

### 接口

- `tools/s2s/vision.py`：`ask(images, prompt, **override) -> str`，按 `vision` 配置调用运行器；图片超过 `max_images_per_call` 时报错，不自动拆分。
- `tools/s2s/agent.py`：`run(role, prompt, attachments=[], images=[], **override) -> str`，按 `agents.<role>` 配置调用。
- `tools/s2s/asr/__init__.py`：后端注册表与 `get_backend(name=None)`；`base.py` 定义 `transcribe(audio_path, start=None, end=None) -> list[Sentence]`，`Sentence` 字段对应 `prompts/00-数据约定.md` 4.2（未编号前用 `start`、`end`、`text`、`speaker`、`clarity`）。`grok.py`、`doubao.py` 只放空壳，调用时抛出“未实现”，由 T3 实现。

### 测试

- 配置解析、环境变量覆盖、角色继承的单元测试（不调用模型）。
- 一个标记为 `live` 的测试：用 ffmpeg 从 `videos/sample/E01.mp4` 第 20 秒取一帧，分别用 `opencode-go/deepseek-v4.1-flash` 和 `opencode-go/glm-5.3-flash` 调用 `vision.ask`，用 `S2S_VISION_MODEL` 切换。
- 一个 `live` 测试：`agent.run("角色卡", "只回复 OK")`。
- `uv run pytest -m "not live"` 默认跑单元测试；`uv run pytest -m live` 跑实际调用。报告中写两种的实际结果。
