## 完成内容

1. 口型记录：新增 Schema，支持规则、像素、主动说话人模型和复核扩展；曲线时间接受 `MM:SS.sss`，对白起止保持 `MM:SS.s`。检查句号存在、文本和起止与同目录声音记录一致、镜头存在、轨迹所属镜头、重复编号及依据帧存在。坐标错误不阻止文本、时间和依据帧检查。
2. 声纹聚类：新增 Schema，检查句号引用、声线格式、待定句、类别声明、类别句数、参与聚类句数、代表句归类、矩阵维度与声线顺序；检查约束冲突和 `cannot-link` 中的句号引用。
3. 声纹候选：复用现有 `声纹候选.schema.json`，新增候选角色对全剧角色卡的引用检查。角色卡缺失时只检查编号格式；角色卡存在但无法解析时报告错误。检查字符串集号与目录、声线集号一致。
4. 人声段：新增 Schema，检查非负数值秒、起止先后、按起点排序及不重叠；允许相邻段首尾相接。
5. 裁定迁移：新增 Schema，新句号引用单集目录的声音记录，旧句号只检查格式、不检查当前是否存在；支持历史未匹配条目的 `新句号: null`，状态限定为 `已沿用`、`待确认`、`未匹配`。

### 扩展黑板类型校验

`tools/validate.py` 支持口型记录、声纹聚类、声纹候选、人声段和裁定迁移。类型默认按文件名识别，任意文件名可用 `--type` 指定。

```bash
uv run python tools/validate.py 剧目/样本剧/E01/口型记录.json
uv run python tools/validate.py 剧目/样本剧/E01/声纹聚类.json
uv run python tools/validate.py 剧目/样本剧/E01/声纹候选.json
uv run python tools/validate.py 剧目/样本剧/E01/素材/人声段.json
uv run python tools/validate.py 剧目/样本剧/E01/素材/回听/裁定迁移.json
```

`--type` 可用中文类型名；英文别名依次为 `lipsync`、`diarization`、`voiceprint_candidates`、`speech_regions`、`decision_migrations`。

口型记录的依据帧支持绝对路径、相对本集目录的路径和相对当前工作目录的项目路径；项目路径校验须从项目根目录执行。裁定迁移从所属 `素材/` 的上级单集目录读取声音记录。声纹候选从单集上级目录读取全剧角色卡，缺少角色卡时仅检查角色编号格式。
