## 需要编排者合并的共享改动

T1 授权的共享文件已直接建立，无额外依赖、模型配置或 README 段落待合并。其他共享需求、提示词和任务文档未修改。

`.env` 需在具备权限的环境补齐。以下命令只复制指定两行并追加空的 `XAI_API_KEY`，不输出密钥，且不会覆盖已有 `.env`：

```bash
python3 - <<'PY'
from pathlib import Path
import re

required = {"ARK_DOUBAO_API_KEY", "ARK_DOUBAO_PROXY"}
selected = {}
for line in Path("../v2t/.env").read_text(encoding="utf-8").splitlines():
    match = re.match(r"\s*(?:export\s+)?(ARK_DOUBAO_API_KEY|ARK_DOUBAO_PROXY)\s*=", line)
    if match:
        selected[match[1]] = line
missing = required - selected.keys()
if missing:
    raise SystemExit("缺少变量：" + ", ".join(sorted(missing)))
with Path(".env").open("x", encoding="utf-8") as target:
    Path(".env").chmod(0o600)
    target.write("\n".join(selected[name] for name in sorted(required)) + "\nXAI_API_KEY=\n")
PY
```
