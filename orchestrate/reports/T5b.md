# T5b 报告

状态：完成

## 完成内容

1. 新增 `临时人物`、`角色变更申请`、`加密帧索引` 三类 Schema，检查必填字段、字段类型、编号、枚举和额外字段。临时人物和独立角色变更申请的顶层为数组，加密帧索引的顶层为对象。`状态.json` 内的申请条目使用与独立申请 Schema 相同的结构。
2. 补齐引用检查：动作执行者、动作对象和归属表说话人的临时人物编号必须在同目录 `临时人物.json` 中声明；不回退到上级目录。映射非空时必须引用角色卡中的角色；申请中的涉及角色必须存在于角色卡。临时人物还检查所属片段、出现镜头及编号与片段的一致性；申请检查编号集号、提出集和重复编号。
3. 按 4.9、4.10 补齐镜头表与片段表校验：镜头首尾覆盖时长、相邻镜头相接，帧文件名与镜头对应、时间升序且不越界；片段必须按顺序恰好覆盖所有镜头一次，起止时间与边界镜头一致，前后衔接正确。零时长空镜头表及配套空片段表仍可用于初始化。全剧状态 Schema 已符合 4.14，无需修改；新增测试覆盖全部状态枚举、字段类型、必填字段和集号重复。
4. 加密帧索引检查正数帧率、起止时间、帧文件名、文件名与时间的一致性、帧时间排序和范围。`帧.json` 自动识别为加密帧索引，也支持 `--type 加密帧索引`。
5. 黑板初始化增加 `片段表.json` 和 `临时人物.json`，保留已有文件。引用镜头表的列表字段错误地写成 `null`、数值等内容时，返回校验错误，不异常退出。
