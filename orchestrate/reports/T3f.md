## 完成内容

### 双路交叉核对

- `tools/asr_cross.py` 从 `asr.cross_check` 读取启用状态、主路和副路；代码不固定后端。传入哪一路结果就直接复用，缺少的一路才调用对应后端。两路均提供结果时不需要读取视频，也不初始化识别后端。
- 按实际时间重叠做有序动态规划，支持一对多和多对一；复用 `s2s.sub_align.comparison_normalize` 处理标点、空白、全半角、中文数字与数字时刻。文字差异很大仍允许时间配对，以不一致交回回听。
- 保留每条主路句子的文本、起止时间、听辨和声线；副路多句拼接比较。多条主路对应一条副路时，按归一化字符对齐分配副路原文片段，不合并主路人物或改变主路断句。仅副路句子按副路时间插入，其声线另配编号，不把副路同号声线当成主路人物。
- 重叠的台词字幕作为第三方原文参考，包括时间落在句内、起止相同的单帧字幕；字幕不决定采用哪路。非一致句生成阻断级识别问题，依据包含主路、副路及字幕原文。再次合并更新同一句的问题；同一时刻的多句分别保留问题。既有问题的句号引用随插句更新。
- 写入前在暂存副本调用现有校验器，备份既有声音记录和待核对，再写回并复验。备份位于本集 `素材/回听/备份/`，每轮独立目录；名称中的 `Z` 为 UTC 存储标识。

### 人工回听页

- 默认显示非“一致”、非“人工确认”的句子，优先级优先、时间次之；`--全部` 显示全部句子。
- 每句有原句和前后各 1.5 秒的上下文 AAC/m4a 片段，裁到视频有效范围，单声道、24 kHz、64 kbit/s。页面引用相对路径，展示最大重叠镜头的代表帧及三路原文，并高亮原文差异。
- 原生 HTML、CSS、JavaScript，无外部依赖或网络资源。提供播放、上下文、重复播放、三种来源选择、手改、听辨、备注、删除及撤销本句决定。
- 实现空格、C、1/2/3、J/K、E 快捷键；输入框内不劫持输入，Esc 返回当前句标题。顶部显示已处理数；表单具有标签和可见焦点。
- 浏览器本地存储保存决定和备注草稿；读写和获取存储对象均有异常处理。存储不可用时仍可操作、导出，并提示离开前导出。存储按本集及声音快照隔离，声音记录变化后不套用旧进度。

### 裁定应用

- 导出 `回听结果.json`，包含声音快照及已完成决定；未选来源的备注草稿、不完整文本不进入结果数组。
- 应用时核对快照，拒绝未知或重复句号、无效听辨、空的非删除文本，以及选定来源与最终文本不符的记录。声音已变化时要求重生成页面。
- 写回最终文本与听辨，核对状态改为人工确认，保留决定来源和备注；删除句子后重新编号。对应的识别回听问题改为已裁定，已删除句的结构化引用移除，裁定历史保留原句号。
- 生成 `素材/回听/句号对照.json`，包含全部旧句号，删除项为 `null`。覆盖上一轮对照前，将旧对照随黑板备份保留。写回后分别调用 `s2s.validate.validate_file` 校验声音记录与待核对。

## 需要编排者合并的共享改动

### 1. 配置

在 `config/models.json` 的 `asr` 中增加 `cross_check`，保留既有 `backends`：

```json
"asr": {
  "provider": "grok",
  "cross_check": {
    "enabled": true,
    "primary": "grok",
    "secondary": "local"
  }
}
```

`provider` 仍供单路工具使用；交叉工具只读 `cross_check.primary` 和 `secondary`。两者必须不同且非空，`enabled` 必须为 `true`。主副路交换只改配置。实际本地模型由既有 `asr.backends.local.model` 决定，本轮配置为 `qwen3-asr-0.6b`。注册表和本地后端配置在当前工程中已存在，无需本任务补注册。

没有新增 Python 或 JavaScript 运行依赖。Node 仅用于测试；回听页离线运行不需要 Node。音频导出复用工程既有 ffmpeg 路径。

### 2. 数据约定

可追加到 `prompts/00-数据约定.md` 的声音记录一节，并同步引用声音记录的相关提示词：

```json
{
  "核对": {
    "状态": "不一致",
    "主路": "能出什么事，老是看着呢。",
    "副路": "能出什么事，老师看着呢。",
    "字幕": "能出什么事 老师看着呢",
    "优先级": 2
  }
}
```

`核对` 是声音条目的可选字段；出现时，上述五项必填。状态为 `一致`、`不一致`、`仅主路`、`仅副路`、`人工确认`。人工确认后另加 `决定来源`，取 `主路`、`副路`、`字幕`、`手改`，及字符串 `备注`。删除决定的句子不再保留于声音记录，删除依据保留在待核对裁定历史及句号对照中。

优先级为 1–3，1 最高。比较使用归一化文本的 Levenshtein 相似度：

1. 仅副路，或不一致且相似度小于 0.6：优先级 1。
2. 不一致且相似度至少 0.8，同时归一化后的重叠台词字幕与任一路完全相同：优先级 3。
3. 其他情况：优先级 2。

两路一致不代表已通过人工或独立验收；字幕和优先级只提供回听参考。

回听导出格式：

```json
{
  "声音快照": [],
  "结果": [
    {
      "句号": "E01-S001",
      "决定": "主路",
      "最终文本": "今天必须说清楚。",
      "听辨": "清楚",
      "备注": ""
    }
  ]
}
```

`声音快照` 为生成页面时完整声音记录数组；`结果` 仅包含已完成决定。决定取 `主路`、`副路`、`字幕`、`手改`、`删除`。删除的最终文本为空。非删除记录的最终文本不得为空；选择固定来源时须与对应原文一致，修改内容使用手改。
