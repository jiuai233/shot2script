## 完成内容

### 流程与约束

- `asr_cross.py` 合并后按顶层 `diarize.enabled` 自动运行声纹。只写回非待定句的 `声线`，文本、时间、听辨与交叉核对状态不变；依据、置信度及冲突写入本集 `声纹聚类.json`。不配置或禁用时保持原行为。
- Grok 按词与句重叠时长确定主标签，标签纯度、软权重及声纹最低相似度可配。标签只在同一原始响应窗口内有效；同窗口选最近成功响应，局部补识别不覆盖整集标签命名空间。
- 口型只使用与当前句号、时间、文本一致的画内记录。同一唯一开口轨迹组 must-link，不同组同时出声 cannot-link；硬约束冲突保留分离并记录。单句多个轨迹组开口不连接这些组，登记冲突。
- 人数上限来自显式参数或现有角色卡，最终目标为上限加 1；遇 cannot-link 不强并。每类提供最多三句代表句，逐句提供实际参与的合并依据。置信度为截断到 0–1 的类中心余弦值，不是校准后的身份概率。

### 跨集参考与评测

- `tools/voiceprint.py 入库 <剧目目录> <集号>`：只积累归属角色编号、确定度为确认、听辨为清楚且向量有效的句子；保存每集均值及句数，跨集按句数加权。同集重入库替换贡献，不重复计数；撤销确认会撤掉该集旧贡献。
- `比对`：每个声线类输出最多三个角色候选与相似度，写入本集 `声纹候选.json`，不修改归属表。待定句依据聚类侧表排除；侧表文本、时间或非待定标签过期则拒绝比对。不同模型、版本或预处理拒绝混用。
- 声纹向量及各集均值只在本机临时黑板的 `声纹/` 下保存，目录 0700、文件 0600；候选、终端输出和报告没有向量数据。
- `评测` 支持人工 `标注.json` 和声线到人物映射，统计覆盖率、纯度、拆分类数及有映射时的身份准确率。未匹配与待定计入总分母；`回听结果.json` 另算文字裁定一致率，不充当说话人真值。

## 需要编排者合并的共享改动

### 1. 配置与依赖

在 `config/models.json` 顶层追加以下字段；不给人数上限时可省略 `max_speakers`，代码会读取角色卡人数，无角色卡则不强制限制：

```json
"diarize": {
  "enabled": true,
  "model": "campp",
  "threshold": 0.6,
  "constraints": ["grok", "lipsync", "max_speakers"],
  "grok_weight": 0.15,
  "grok_purity": 0.7,
  "grok_min_similarity": 0.2,
  "threads": 2
}
```

未新增 T3d 之外的依赖。若尚未合并 T3d 依赖，需加入 `sherpa-onnx==1.13.8` 和显式 `numpy>=2`；本轮使用 `uv run --with sherpa-onnx==1.13.8`，未修改 `pyproject.toml` 或 `uv.lock`。
