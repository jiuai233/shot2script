# T5 报告

状态：部分完成。四个工具、12 类 JSON Schema 和要求的正反例测试已完成；临时人物逐编号存在性校验缺少声明格式，真实单集覆盖检查缺少成稿输入。

## 完成内容

1. 黑板初始化：建立数据约定第 2 节的目录与空文件；记录文件为数组，镜头表与状态为对象；初始状态为 `进行中`；已有文件保留。
2. JSON 校验：检查必填字段、类型、枚举、编号格式与重复、集号一致性、时间格式与起止顺序，以及镜头、句号、动作、角色、问题、场景和声线的结构化引用。依据、说明和对白文本不作为编号解析。
3. 覆盖检查：检查漏句、重复句、按时间排序的句序、关键动作覆盖，以及正文台词与所列声音记录拼接文本的逐字一致性。比较前统一全半角并去除标点与空白；检查未知编号、未映射对白、行号越界和重复行映射。
4. 剧本检查：识别集标题、场景行、人物行、△ 与对白；只检查描述和对白括号的指代用词，台词原文不检查。检查特殊声音形态括号中的动作词、场景格式与连续编号、紧邻人物行、角色卡名称和正式稿残留。描述名、画面字幕照录内容及书名号内作品名称得到保护；词表可通过 `--词表` 指定。

## 未完成与问题

1. 临时人物 `E01-P01-T1` 没有独立声明表。现有工具校验编号格式、集号和所属片段是否存在，不能证明具体 `T1` 已被声明。角色编号 `C...` 的存在性已通过角色卡检查。
2. `角色变更申请` 的条目结构尚未定义，当前 Schema 校验为对象数组，未限定内部字段。
3. “它们”既能指人也能指物：明确人物先行词的用例会报错，物品先行词的用例不报；缺少明确先行词时不能机械认定，仍需独立验收。
4. 真实样本的全套覆盖检查等待声音、动作、对照表与工作稿；机械校验不验证素材真实性或画声归属。
