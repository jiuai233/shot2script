# 编排

任务单在 `tasks/`，执行报告在 `reports/`，运行日志在 `logs/`，执行者会话在 `sessions/`。

## 派发

```
orchestrate/dispatch.sh <任务编号> [补充说明]
```

执行者默认 `pi --model openai-codex/gpt-6.1-sol --thinking high`，可用 `WORKER_MODEL`、`WORKER_THINKING` 切换。每个执行者先读 `tasks/_通用说明.md`，再读自己的任务单。

## 验收

每个任务完成后，编排者：

1. 读报告，按报告中的命令复跑测试和实际运行。
2. 检查文件边界：执行者只改了任务单列出的文件。
3. 合并报告中的共享改动（依赖、配置、`tools/README.md`、数据约定补充）。
4. 需要总工决定的事项汇总给总工。
